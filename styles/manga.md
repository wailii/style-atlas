# 漫画分镜（manga）

日本漫画的一页：斜切的分格、贴上去的网点纸、从四周往中间收的集中线、一格瞪大眼睛的特写、手写拟声字压过格线、刺刺的爆炸气泡。黑白，最多加一种双色印刷的专色。格子按从右往左的阅读顺序一格格「砸」进来。

出处：抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》里录屏的 The Notturno Experience（意大利开胃酒品牌的滚动 3D 叙事网页）中的黑白漫画跨页、眼睛特写和蓝色液体飞溅；漫画网点纸的做法见 https://en.wikipedia.org/wiki/Screentone ，日本漫画的分格和阅读顺序见 https://en.wikipedia.org/wiki/Manga 。

```js
// 网点纸：固定点距的两种网（不是连续网点），45°；再加墨线和纯黑
toneCanvas(src, w, h, { p: 4.4, cuts: [.16, .5, .82], edge: .07 })   // 点距 4.4px；深网半径 .4p、浅网 .24p
focusLines(w, h, { n: 120, inner: .74 })        // 集中线：白底黑楔形，中间留一个参差的洞
SLAM = "cubic-bezier(.2,1.5,.35,1)"             // 一格 380ms：硬切出现、画面从 1.35 倍落回、头 12% 反白
// 常驻：瞳孔每 70ms 抖 ±1.1px；ゴゴゴ 每 125ms 抖 ±1.5px ±4°；集中线每 250ms 换一版
```

## 一眼认出（不能改）

- 一页里有分格：格框黑粗 2.6px、格间白缝 7px，至少一条斜切的格线
- 灰色全是网点纸：固定点距、硬边分区，两档网 + 纯黑 + 纸白，没有平滑灰
- 有一格集中线（白底黑楔形往中心收），有一格速度线
- 有一格极近的眼睛特写：瞳孔缩小、四周留白、额头一排竖线
- 拟声字（ドン、ゴゴゴ、轰）白字粗黑边，压过格线，不被格子裁掉
- 刺刺的爆炸气泡装标题，竖排旁白框
- 动作按阅读顺序：右上 → 左下，一格一格砸进来，砸到时整页一抖

## 颜色

- 纸 `#FBFAF6`，墨 `#0C0C0C`
- 专色 `#00A0E9`（双色印刷的青）：只用在拟声字错版、名次数字、底栏选中角上的网点，一屏不超过三处
- 放心改：专色换成双色刊常用的红 `#E60033`；不能改：主体只有黑、白、网点

## 字体

- 拟声字、名次、数字：Dela Gothic One（日文假名极粗）；中文拟声字落到 ZCOOL QingKe HuangYou
- 气泡里的台词、标题：Noto Sans SC 900
- 旁白框：Noto Serif SC 900，竖排
- 刊头：Noto Sans SC 900，白字 + 3px 白描边，外面再一层 9px 黑描边（杂志 logo 的双层描边）

## 真图怎么处理

- 先按原图明暗拉伸（3%～97% 分位），再分四档：最暗切成纯黑，中暗贴深网（点半径 .4 × 点距），中亮贴浅网（.24 ×），最亮留纸白
- 网点是逐像素算的：每个像素旋转 45° 找最近的网格中心，按距离给覆盖率，所以每一档里的点一样大，边界是硬的（像美工刀裁过的网点纸）
- 亮度梯度大的地方描黑线（edge 阈值 .07～.15，主图低一点，小图高一点）
- 主图只取原图中间一小块（宽 27%），形体够大网点才贴得出形状；然后在上面压一层集中线，中间留洞
- 没封面的小格：集中线 + 线条图标，图标里面填网点、外圈 7px 白边

## 线和形

- 分格：页面坐标 370 宽，格框是多边形；一条下沿向左下斜、一条向右下斜，第二排中间一条竖向斜分隔
- 格子内容用 clip-path 裁成同一个多边形；格框画在单独的 SVG 上（不然 clip-path 会把框也裁掉一半）
- 集中线：120 条楔形，根部宽 0.6～5px，起点在内椭圆（.74 × 半宽）附近随机进出，外面全涂纸白
- 速度线：横线 64 条，长 30～170px，粗 0.5～3.7px，圆头
- 眼睛：上眼皮是两条贝塞尔夹出来的黑色月牙（中间厚两头尖）、外眼角两片睫毛、下眼皮断续线；虹膜里 22 条放射线 + 上沿一块黑影 + 两个高光；眉毛压低，额头竖线 3px 一根

## 动效

- 砸格：硬切出现 → 格内画面从 1.25～1.5 倍落回 → 头 12% 反白一下 → 格框同时从 1.05 倍弹回；380ms，SLAM 缓动
- 阅读顺序：特写（300ms）→ 主图（900ms）→ 数据格（1380ms）→ 标题格（1640ms），每格间隔 250～500ms
- 眼睛：先像睁眼一样从 scaleY .06 张开，再瞳孔从 11 缩到 4.6（受惊）；之后一直「瞳孔地震」
- 集中线从 2.2 倍收进来；ドン 从 3.4 倍、-30° 砸下，砸到时整页按 7 格 steps 抖 7px
- 速度线从右边射进来；数字 520ms 跳到真实热度
- ゴゴゴ 一个一个冒出来，之后每 125ms 原地抖
- 切换（底栏）：一张白纸从右往左翻过去，内容跟着 rotateY 18°，翻完四格重新砸一遍

## 组件

- 刊头：双层描边 logo + 黑底「第 22 话」+ 日期；右边圆气泡按钮「听！」，点了变刺气泡「停！」，并砸出一个「轰」
- 主卡（一整页）：特写格（眼睛 + 竖排旁白）→ 主图格（网点图 + 集中线 + 竖排名次）+ 数据格（速度线 + 大数字 + 来源人数）→ 标题格（刺气泡 + 关键词反白 + 日期小框）；拟声字压在格线上
- 摘要：方框旁白，4px 实心黑影
- 列表：每条一格，左边竖条写名次，右边网点小图或集中线小图 + 角落拟声字；点开整格反白一帧，弹出圆气泡（尾巴指向标题）装摘要
- 底栏：上沿 3px 黑线；选中项是歪的黑块 + 角落一小片专色网点

## 换到别的东西上

- 网页
  - 首屏是一整页跨页：大格放主视觉，小格放卖点；滚动一屏翻一页（页面从右往左翻）
  - 章节标题放进刺气泡；鼠标停在格子上，格子里的集中线收紧一圈
  - 宽屏照样右上起读：第一格放右上，格子排成两到三列的斜切网格
- App
  - 一屏就是一页漫画，最多四格；按钮做成气泡，按下时气泡变刺
  - 关键反馈用拟声字（成功「ドン」、刷新「ザッ」、出错「ガーン」），压在按钮上 0.6s 消失
  - 加载：一格一格砸出来，不用转圈
- Dashboard（图表、大数字、表格）
  - 大数字放在速度线格里，Dela Gothic One + 白描边，跳数字时速度线一起射
  - 折线图用黑线 + 线下贴浅网（不填灰）；柱状图柱子贴深网，最高那根涂黑 + 拟声字
  - 表格每行一格，格间 7px 白缝，表头竖排；异常值那格加集中线
- 视频（镜头、转场、声音）
  - 镜头：一格一个镜头，镜头内只做推近和抖；最重要的那一下给眼睛特写 + 瞳孔收缩
  - 转场：翻页、格子砸进来、白闪一帧；拟声字跟着声音同一帧出现
  - 声音：重低音的「咚」、紧张时持续的低频轰鸣（对应ゴゴゴ）、翻纸声；台词以字幕气泡出现
  - 节奏：静态格停 0.6～1.2s，砸格 0.38s
- 海报设计
  - 一张跨页：上面一格眼睛特写、中间斜切大格放主体 + 集中线、下面刺气泡写主标题
  - 拟声字做最大的字，可以出血；专色只用一次

## 容易做坏

- 用连续网点（半调）冒充网点纸——网点纸是固定点距、分区贴的；连续半调是纸拼贴和美漫的做法
- 用灰色、渐变填充；中间调必须是网点
- 拟声字被格子裁掉——它要放在格子外面一层
- 格子全是直角正方形，像相册；至少要一条斜格线
- 格框和内容一起 clip，框只剩一半粗
- 眼睛画得太小、太居中，不是特写；特写要被格子边切掉一部分
- 网点图用原图全幅，图标、小字一片糊；只裁中间一块
- 专色到处用，就不是双色印刷了

# 发布会（w-keynote）
一个整屏高的黑白交替长页：巨大标题、一件产品随滚动放大和旋转、规格用超大数字、最后让你自己选颜色。全页只讲一件东西，一段只说一句话。适合产品发布页、版本发布页、重要功能的介绍页。
出处：Apple 产品页（https://www.apple.com/）。

## 一眼认出（不能改）
- 首屏纯黑底，超大白色标题（100px 以上），一行副标题，一个白色胶囊按钮加一个文字链接
- 一段 sticky 舞台：产品留在屏幕中央，随滚动放大、转向，每个阶段只有一两行大字
- 背景在滚动中由黑变浅灰，导航栏的颜色也跟着反色
- 规格是一排超大数字（90px 左右）加小号单位和一行说明，数字进入视口时从 0 数上来
- 配色区：一排小圆点，选中的有外圈，产品实时换色
- 导航细、居中，滚动后变半透明磨砂
## 颜色
- 黑 `#000`；浅灰 `#F5F5F7`；白字 `#F5F5F7`；深字 `#1D1D1F`；说明灰 `#86868B`
- 强调青绿 `#2BD9C0`，只用在小标题、链接、产品灯带
- 产品配色：银白 `#CFD2D6`、石墨 `#34363B`、靛蓝 `#1C2A78`、琥珀 `#B03A08`
## 字体
- Inter 800 / 700 + Noto Sans SC 700，大标题字距 -0.035 到 -0.045em
- 说明文字 400，21 到 25px，灰色
- 数字一律 tabular-nums
## 真图怎么处理
- 不用照片，产品是 three.js 即时画的 3D 模型：圆角机身、双风扇、金手指、挡板、灯带，全部由几何体拼成
- 光照靠 `RoomEnvironment` 的环境贴图，加一盏主光和一盏青色轮廓光
- 贴图只有铭牌一张，用 canvas 画成纹理
## 动效
- 滚动驱动：产品姿态、背景色、文案透明度都是同一个滚动进度的函数，进度每帧向目标靠 14% 求平滑
- 风扇持续旋转，两个转速略有差别
- 数字从 0 数上来 1.6s；导航滚过 10px 后变磨砂
- 配色区：松手后继续带惯性旋转，空闲时缓慢自转
## 组件
- 导航：品牌、概览、规格、配色、「预订」胶囊
- 舞台：标题区、五段文案、右侧圆点进度
- 规格格：四列，每列上线下说明，列间 1px 细线
- 配色区：大号标题、四个色点、色名、可拖动的 3D 卡片
- 页脚：一个按钮和一行免责说明
## 学什么交互
- 滚动即播放 → 一次只讲一件事，读者用滚动控制速度 → 放到后台：新功能上线说明页，一段滚动演示「申请、审批、交付」三步，而不是三张截图。
- 背景黑白交替 → 用底色变化分段，不需要分割线和卡片 → 放到后台：月报长页里，概览用深色、明细用浅色，段落边界一目了然。
- 规格大数字 + 进入视口再数 → 先抓住「多大」再看说明 → 放到后台：资源概览页的总卡数、总费用用大号数字，进入视口时数一遍，对比旧版更有冲击。
- 配置器实时换色、可拖拽 → 选择的结果马上看得到 → 放到后台：模型或套餐配置页，选规格时右侧即时显示价格和配置摘要。
## 换到别的东西上
- 适合：产品发布、年度报告、功能介绍页
- 不适合：需要频繁操作的后台，滚动绑定的动画会妨碍效率
## 容易做坏
- 滚动距离太短，动画一闪而过；太长又让人失去耐心
- 产品姿态在相邻阶段变化太大，看不清是同一件东西
- 文字块和产品重叠，文案盖在模型上
- 手机上照搬桌面的 sticky 长度
- 每段同时说多个卖点

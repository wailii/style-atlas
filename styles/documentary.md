# 纪实摄影（documentary）

一本严肃的图片杂志：大幅黑白照片压在白纸上，粗细双线刊头，照片下面是一段长图说——写清照片里是什么、谁拍的、用什么相机怎么拍的。旁边摊着一张底片小样，摄影师用红色油性笔圈出选中的那一帧、在废片上打叉。一切按事实来，不煽情。

出处：图鉴原有 60 种全是插画、版画、复古界面这类风格化画法，缺一组看起来像真照片、真光线、真镜头的风格，于是加了「写实 · 影像」组（61–70），这是其中一种。画面语法来自真实的纪实摄影出版：Magnum Photos（https://www.magnumphotos.com ）的图片故事和《Magnum Contact Sheets》（Kristen Lubben 编，Thames & Hudson，2011）里摄影师用油性笔在小样上选片的痕迹；世界新闻摄影奖（https://www.worldpressphoto.org ）严格的图说和署名规范；高感光度黑白胶卷（Tri-X 一类）的颗粒和反差。参考页的照片全部来自 Unsplash（Unsplash License），经 Hugging Face 上的镜像数据集 `wtcherr/unsplash_5k`（https://huggingface.co/datasets/wtcherr/unsplash_5k ）取用，EXIF 来自每张图旁边的 `.json`：Anna Schroeder（https://unsplash.com/photos/_Yv4x4E9Iec ）、Redd F（https://unsplash.com/photos/y692nLSXiaU ）、Mak（https://unsplash.com/photos/QwsCqHTim98 ）、Waqas Saeed（https://unsplash.com/photos/352QM42iN7A ）、Madalena Veloso（https://unsplash.com/photos/zeNeAUwoJvs ）、Dana Cristea（https://unsplash.com/photos/Dw0-lA3qvr4 ）。这些图在页面上都标「示意图」，图说只描述照片本身，与新闻事件无关。

```js
// 1) 通道混合 Y = .42R + .48G + .10B（偏红滤镜：天空压暗、皮肤提亮）
// 2) 自动曝光：2% / 98.5% 分位拉到两端
// 3) 局部反差：Y += (Y - blur(Y, W/50)) × .45
// 4) 胶片曲线：smoothstep(-.02, 1.04, Y) ^ 1.08；四角压暗 .32 × r^2.4
// 5) 颗粒：1/1.25 分辨率高斯噪点放大（团状），幅度 .035 + .075 × sqrt(1 - (2Y-1)²)，中间调最重
tri(img, w * 2, h * 2, { fo: [焦点x, 焦点y], grain: 1.1 });
// 小样：35mm 片条（片边 16px、齿孔 4.2×4.6、片号「12 ▸12A」），竖拍的帧在片格里横躺（rot: -90°）
// 红色油性笔：路径四边微弯、角圆、收笔过头；沿路径每 .45px 戳一个 1.6×3px 的小椭圆，透明度 .42～.82、7% 概率断开（蜡在光面相纸上的丝）
```

## 一眼认出（不能改）

- 白纸上的大幅**黑白**照片，满幅出血；颗粒清楚、黑是真黑、四角压暗
- 照片下面一定有图说：「**示意图**」+ 照片里是什么 + 摄影师 / Unsplash + 真实 EXIF（相机 · 焦距 · 光圈 · 快门 · ISO）
- 一张底片小样：两条黑色 35mm 片条，有齿孔和片号，竖拍的帧横躺；**红色油性笔**圈出选中的帧并打勾，废片打叉
- 粗细双线刊头 + 宽字距的小号栏目签（PHOTO ESSAY · 图片报道）
- 标题和正文都是衬线；列表是一条条细线隔开的文字，不加缩略图
- 列表中间插一张整幅照片，图说注明「与上下新闻无关」

## 颜色

- 纸 `#FBFAF7`、墨 `#111111`；次要文字 `#5F5D58`、`#8B8882`；分隔细线 `#DEDBD4`
- 照片全部中性黑白（暗部极轻微偏暖，r : g : b = 1 : .995 : .985）
- 唯一的颜色是油性笔红 `#D1261A`，只用在小样上的手画记号；界面上任何地方都不用红
- 小样相纸 `#F4F2EC`、片基 `#0D0D0C`、齿孔透光 `#CFCCC4`、片号 `#A9A59A`

## 字体

- 刊头、标题、正文、列表：Noto Serif SC（900 / 600 / 400）
- 栏目签、署名：Inter 500～600 全大写，字距 .12～.2em，8.5～10px
- 图说：Noto Sans SC 400 11.5px；EXIF：IBM Plex Mono 9px
- 编号用衬线数字 `02`，不用等宽

## 真图怎么处理

- 选图：街头、人、劳作、孩子、老人、影子、俯拍——有人、有事、有光影关系的；摆拍人像、产品、纯风景不对
- 全部过 `tri()` 转黑白；`fo` 焦点放在人身上；逆光、雾天的图会偏灰，靠自动曝光和局部反差拉开，不要再加滤镜
- 图说写**照片里真实可见的东西**（从原图说明翻译），不写和新闻有关的推测；标「示意图」
- 署名「摄影 X / Unsplash」，EXIF 从照片旁边的 `.json` 读，没有就写「EXIF 未记录」
- 小样上的帧和正文用同一批照片：选中哪一帧，头图就换成哪一张，图说跟着换
- 新闻自带的封面（logo、截图）不进这个版式；要放就单独做一条「资料图」，同样黑白处理并注明来源

## 动效

- 照片「显影」：从一张白纸开始，暗部先出来，再到满反差（brightness 2.6 → 1、contrast .25 → 1，2.4s）
- 油性笔：照片显影后 1.5 秒，红框沿路径画出来（0.9s，前 74% 画框，后面打勾）；废片上的叉已经在
- 刊头、栏目签、图说、小样、正文依次上浮淡入（6px，0.8s，间隔 150～200ms）；列表逐条（90ms）
- 点小样上另一帧：红框重画到那一帧，头图重新显影（1.2s），图说换成那一帧的
- 不用弹簧、不用缩放；所有东西都慢、稳

## 组件

- 刊头：衬线「AI 热点」+ 右侧「纪实 · 10.22 · THU」+ 粗细双线
- 栏目签：`PHOTO ESSAY · 图片报道` + 右侧 `01 / 08`
- 头图：390×248 满幅黑白 + 图说三行（示意图 / 署名 / EXIF）
- 小样：标签 `CONTACT SHEET · 小样` + 右侧状态（「点一帧换图」→「选用第 4 帧」）；两条片条六帧，可点
- 正文：栏目签「头条 · 热度 455」→ 衬线大标题 → 128 字摘要 → 来源 / 参与 / 主要来源名
- 列表：衬线编号 + 衬线标题 + 一行灰色读数（来源 · 参与 · 热度）；点开展开摘要，标题加下划线
- 插页照片：整幅黑白 + 图说 + 「与上下新闻无关」
- 页脚：一段灰色小字说明照片来源和处理方式
- 底栏：纸色底、顶上一根黑线；选中项黑字 + 下划线

## 换到别的东西上

- **网页 / 落地页**
  - 首屏一张满幅黑白大图（16:9 或 3:2），图说放在图下左栏，标题和导语放右栏；12 栏网格，正文栏宽 ≤ 38 个汉字
  - 往下是「图片故事」：大图、两张并排、一张小样交替；每张都带图说和署名
  - 小样做成可点的选片器：点哪帧，上面的大图换哪帧
- **App**
  - 参考 `gallery/s-documentary.html`：头图 + 小样 + 衬线正文 + 细线列表
  - 适合新闻、深度报道、档案、田野调查、公益项目记录；按钮只用文字链接（衬线 + 下划线）
- **Dashboard**
  - 纸白底、双线刊头；模块之间只用 1px 细线，不用卡片
  - 大数字：Noto Serif SC 900，黑；下面一行像图说的小字写数据来源和口径
  - 图表：黑白——柱是实黑、折线 1.5px 黑、第二系列 50% 灰；网格只留基线；关键点用油性笔红圈出来（手画的圈，只圈一个）
  - 表格：衬线编号、细线分隔、数值右对齐；被选中的行左边一道红色手画竖线
  - 配图位放黑白照片 + 完整图说，不放图标
- **视频**
  - 镜头：黑白照片定格为主，每张 4～6 秒，缓慢推进或平移（Ken Burns 要很克制，≤ 8%）；中间穿插小样特写：油性笔在帧上画框
  - 转场：硬切或快速白闪（像放大机开灯）；不要溶解、不要滑动
  - 字幕：画面下方白底黑字的图说条；声音：环境声（街道、风、人声）+ 极少的钢琴或低音提琴，快门声做节奏点
- **海报设计**
  - 一张黑白照片占 2/3，下面是衬线大标题和一段图说；一角放一条小样，红笔圈出主图那一帧
  - 只用黑、白、灰和一处红；署名和 EXIF 写全

## 容易做坏

- 黑白处理成灰蒙蒙一片（没拉反差），或者用 CSS `grayscale()` 了事——要通道混合 + 局部反差 + 颗粒
- 颗粒太细像数码噪点，或者亮部、暗部颗粒一样多
- 红色用到界面上（按钮、标签、强调）——红只属于油性笔
- 油性笔画成规整的矢量矩形、等宽线条；要手抖、圆角、蜡质断续、收笔过头
- 小样做成 CSS 圆角卡片；片条没有齿孔和片号；竖拍帧被拉伸塞进横格
- 图说只写「图片来源网络」；或把示意图说成新闻现场；编 EXIF
- 用无衬线写正文，或标题加花哨效果

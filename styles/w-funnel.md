# 产品洞察（w-funnel）
灰米色纸面上的产品分析工具：左边选洞察类型（漏斗 / 留存 / 趋势），主区顶上一句可改的话描述这张图，下面是一张图加一张数据表。黑色粗边、硬阴影、荧光笔标出的可改词，气质偏玩具感。给做增长和产品分析的人，也适合任何「选条件→看图」的分析页。
出处：PostHog（https://posthog.com）；Amplitude（https://amplitude.com）。

## 一眼认出（不能改）
- 灰米底，白色面板带 1.5px 黑边，选中项有 2px 硬阴影
- 配置区是一句话，可改的词有黄色荧光笔底和黑色下划线，点开是下拉
- 漏斗：蓝色实心柱 + 斜纹流失块，柱间白色胶囊标步骤转化率
- 留存：三角形热力表，单色（浅蓝到深蓝），格内写百分比
- 图下方是带序号圆点的数据表
## 颜色
- 底 `#eeede6`，字 `#15150f / #55544a / #8d8c80`
- 数据色只有钴蓝 `#3a45e8`（辅助浅蓝 `#aeb4f7`），荧光笔黄 `#ffe06b`
- 下降和流失用红 `#cf3b2c`，只用在数字上
## 字体
- Bricolage Grotesque 做标题和大数字，DM Sans + Noto Sans SC 做正文
## 真图怎么处理
- 不用照片
## 动效
- 漏斗柱按顺序从底部长出（每根错开 90ms），趋势线 1s 画出
- 抽屉 280ms 从右滑入
- 按钮悬停时上移 1px、出硬阴影
## 组件
- 左栏：洞察类型（带小图标和一句说明）、已保存列表（点开载入参数）
- 标题可直接编辑；保存按钮
- 句子配置栏、图卡片、数据表、右侧用户抽屉（流失 / 完成两个页签）
- 留存格悬停提示人数和比例
## 学什么交互
- 用一句话代替表单配置 → 条件读起来是完整意思，改一个词就行，不用对着一排下拉框 → 在资源台账、费用明细里把筛选写成「显示 [算法部] 在 [近 30 天] 内 [GPU 利用率低于 20%] 的 [服务器]」，点词改条件。
- 图上每一块都能点开看人 → 看到异常马上能下钻到具体对象 → 工单审批漏斗点「驳回」那一段，直接列出被驳回的工单。
- 先切类型，再改句子，图和表同时变 → 一个入口承载多种视角 → 模型调用分析里把「调用量 / 延迟 / 错误」做成同一套句子，只换类型。
- 留存三角热力表用单色深浅 + 悬停读数 → 一眼看出哪一批用户质量高 → 按月申请的资源到期续用率，也可以画成这种三角表。
## 换到别的东西上
- 适合：用户行为分析、审批流转化、任务完成率、续用率
- 不适合：需要大量参数的专业统计工具
## 容易做坏
- 句子里的词看不出能点（缺荧光笔和下划线）
- 流失块和完成块用同一种填充，分不清
- 热力表用多种颜色，读不出深浅
- 抽屉做成跳页，看完回不到图上

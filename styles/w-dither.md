# 一位抖动（w-dither）

只有黑、白和一种黄的产品站：照片实时抖成纯 1-bit，点阵字，粗黑边加硬阴影，按钮按下反色，页面上有一个能转的曲柄。给独立游戏机、小硬件、复古工具、想让人一眼记住的小产品站用。

出处：Playdate（https://play.date）；Panic（https://panic.com）。

## 直接抄

```css
:root{--paper:#f7f5ec;--ink:#111;--y:#ffd400}
canvas{image-rendering:pixelated}
.btn{border:3px solid var(--ink);background:var(--paper);box-shadow:5px 5px 0 var(--ink);position:relative}
.btn:hover{background:var(--y)}
.btn:active{background:var(--ink);color:var(--paper);box-shadow:none;top:5px;left:5px}   /* 按下：反色 + 压下去 */
.card{border:3px solid var(--ink);box-shadow:6px 6px 0 var(--ink)}
input[type=range]::-webkit-slider-thumb{width:14px;height:24px;background:var(--y);border:3px solid var(--ink);border-radius:0}
```

```js
// Floyd–Steinberg：从左到右、从上到下，把量化误差分给右、左下、下、右下
const old=L[k]-bias, nw=old<128?0:255, e=old-nw;
L[k+1]+=e*7/16; L[k+w-1]+=e*3/16; L[k+w]+=e*5/16; L[k+w+1]+=e/16;
// Bayer 8×8：像素亮度和矩阵阈值比较；阈值滑杆 = 给亮度加偏移 bias = T-128
o[k]=(L[k]-bias)>(BAY[y%8][x%8]+.5)/64*255 ? 1 : 0;
// 图在 240×144 的小画布里抖动，再用 CSS 整数倍放大（2×），像素才是方的
// 汉字标题压成 1-bit：用 Canvas 画字，alpha>110 的点涂黑，其余透明，再整数倍放大
```

## 一眼认出（不能改）

- 屏幕和图片只有两种颜色：近黑 `#111` 和奶白 `#F4F1E6`，没有灰
- 照片是抖动出来的点阵，像素是方的、整数倍放大
- 页面颜色只有黑、纸白，加一种黄 `#FFD400`
- 粗黑边（3px）、硬阴影（无模糊，右下偏 5–12px）、零圆角（设备外壳除外）
- 点阵字体作标题和数字；按钮按下反色并位移

## 颜色

- 纸 `#F7F5EC`，墨 `#111`，黄 `#FFD400`，灰字 `#5D5A4E`（只用于说明）
- 屏幕白 `#F4F1E6`，屏幕黑 `#111`
- 不加第二种彩色，不加渐变

## 字体

- Pixelify Sans（拉丁字母、数字）
- 汉字标题用 Canvas 压成 1-bit 后整数倍放大（30px 画、放大 3 倍）；正文用 Noto Sans SC 500，关闭抗锯齿平滑

## 真图怎么处理

- 先灰度、拉对比，裁成 5:3，再缩到 240×144（卡片 200×120）
- 实时抖动，算法 4 种：Floyd–Steinberg、Bayer 8×8、固定阈值、随机噪点；阈值滑杆 40–216
- 图片以内嵌 base64 放进页面，避免双击打开时 canvas 读像素被浏览器拦截；图下小字标「示意图 · 摄影师」
- 人像和有大块阴影的图抖动效果最好；纹理太碎的图（植物、航拍）用 Bayer 比误差扩散干净

## 动效

- 换图：新画面从上往下逐行扫入（260ms），像老掌机刷新
- 按钮：无过渡，按下直接反色
- 底部滚动条用 `steps()` 一格一格走，不走平滑
- 其他一律不做缓动

## 组件

- 顶栏：像素 logo、导航、价格、预订按钮
- 标题区：标签、1-bit 大标题、说明、两个按钮
- 屏幕调校面板：算法分段按钮（悬停预览，点击选定）、阈值滑杆、说明
- 掌机：黄色外壳、黑边屏幕、方向键、A / B、图下署名
- 曲柄：圆盘刻度 + 把手，拖动旋转，读数显示角度和第几张
- 游戏卡片：抖动图、名称、价格、类型；悬停换另一种算法，点击把它放上掌机屏幕
- 规格表：左列黄底

## 学什么交互

- 滑杆实时改变一张图 → 参数和结果之间没有「应用」按钮，拖到哪看到哪 → 放到费用明细或用量看板：拖「阈值」滑杆，列表实时只显示超过阈值的账号，并显示「命中 N 项」。
- 悬停算法按钮就预览，移开还原，点击才定下 → 试错成本为零，用户敢试 → 放到资源台账：悬停「按部门 / 按机房 / 按项目」分组按钮时，表格预览分组结果，点击才切换。
- 旋转式控件（曲柄）连续驱动离散内容 → 一个手势翻很多项，还有读数 → 放到日志回放、监控时间轴：拖动圆盘或时间轴，按刻度切换时间点，旁边读数写当前时刻。
- 按钮按下反色并位移 → 反馈强，点了没有就是没点 → 放到审批页的「同意 / 驳回」，按下时有明确的压下反馈，防止重复点击。
- 全页只有两色加一个强调色 → 强调色只出现在可操作处，用户一眼知道哪里能点 → 放到后台：黄色换成品牌主色，只给主按钮和选中项用。

## 换到别的东西上

- 独立游戏、小硬件、开源工具、极客产品、技术大会页
- 后台只借「滑杆实时」「悬停预览」「按下反馈」；点阵字和硬阴影不要带进去

## 容易做坏

- 图片用 CSS 滤镜假装抖动，放大后出现灰度
- 放大倍数不是整数，像素大小不一
- 加第二种彩色，或者加圆角阴影，风格就散了
- 全页都用点阵字，正文读不动；点阵字只用于标题和数字
- canvas 读本地图被拦截，页面直接空白

# Material 3 Expressive（m3）

Google 2025 年的 Material 3 Expressive：配色从内容图里取，形状库里的曲奇、花、太阳、四叶草当容器和装饰，按钮组按下的那个会变宽，所有动作都是弹簧。

出处：nextlevelbuilder/ui-ux-pro-max-skill（风格表第 76 行 Material 3 Expressive (Mobile)：dynamic color、shape morphing、spring motion）；Material Design 3 官方站（https://m3.material.io）。

```js
// 形状库：半径随角度变化 r(θ) = 1 + a·cos(nθ)；两个形状之间按 k 插值就能互相变形
const SHAPES = { cookie: [12, .07], flower: [8, .16], sunny: [8, .09], clover: [4, .2], soft: [6, .05], circle: [1, 0] };
const shapeR = ([n, a], th) => 1 + a * Math.cos(n * th);
function shapePath(w, h, sA, sB = sA, k = 0, rot = 0, pts = 120) {
  const R = Math.min(w, h) / 2 / 1.2; let d = "";
  for (let i = 0; i <= pts; i++) { const th = i / pts * Math.PI * 2, r = R * ((1 - k) * shapeR(sA, th - rot) + k * shapeR(sB, th - rot)); d += `${i ? "L" : "M"}${(w / 2 + Math.cos(th) * r * 1.1).toFixed(1)} ${(h / 2 + Math.sin(th) * r * 1.1).toFixed(1)} `; }
  return d + "Z";
}
el.style.setProperty("--shape", `path("${shapePath(250, 250, SHAPES.cookie, SHAPES.flower, k, t * .2)}")`);
// 动态取色：封面 40×40 按色相分 36 桶、按饱和度加权，最重的一桶当种子色 → applyTheme(h) 生成整套色调
```

## 一眼认出（不能改）

- 整套颜色从头图里取（种子色 → 主色、容器色、第三色）
- 形状库：曲奇（12 波浪）、花、太阳、四叶草，用来裁图、做编号底、做加载动画
- 按钮组：按下的变宽变圆，旁边的让开
- 列表成组：首尾大圆角，中间小圆角；展开的那条变成全圆角
- 弹簧动效，形状一直在慢慢转

## 颜色

- 全部由种子色色相 h 生成：主色 `hsl(h 55% 42%)`、主容器 `hsl(h 80% 90%)`、次容器 `hsl(h+20 40% 90%)`、第三容器 `hsl(h+60 70% 90%)`、底 `hsl(h 40% 98.5%)`
- 默认（没图时）用 M3 基准紫 `#6750A4`

## 字体

- Roboto Flex（可变字体，标题拉宽到 wdth 130）+ Noto Sans SC

## 真图怎么处理

- 原图不改色；用曲奇形状裁出来，形状每帧转一点（图不动）；播放时形状在曲奇、花、太阳、四叶草之间变

## 动效

- 所有入场用弹簧（Engines.springCurve）：头图放大、编号花形转进来、列表逐条弹入
- 头图轮廓一直慢转；播放时形状轮流变形
- 按钮组：点哪个，哪个 flex 变大、圆角变圆
- 播放按钮里的三角变成一个一直变形旋转的加载形状
- 点列表：编号形状转 90° 放大一点，卡片变全圆角

## 组件

- 顶栏：宽体标题 + 「配色取自头条封面 · 色相 XXX°」小字和色点
- 主卡：曲奇裁图 + 花形编号 + 标题 + 按钮组（热度 / 来源 / 参与）+ 圆角大播放按钮
- 列表：成组卡片，左边形状编号，右边小图
- 底栏：M3 导航栏，选中项图标有药丸底

## 换到别的东西上

- 网页：安卓相关产品、工具类、内容平台；整站配色跟着主图变
- 视频：形状变形转场、颜色跟着画面换
- 换图就换整套颜色，适合多主题内容

## 容易做坏

- 种子色取到灰色（要过滤低饱和、过暗过亮的像素）
- 形状太多太乱；一屏两三种就够
- 动作用普通缓动，没了弹性
- 自己调颜色而不是从种子生成

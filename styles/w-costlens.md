# 成本透镜（w-costlens）
暖米色纸面上的月度费用分析页：一张按天堆叠的大柱图占住版面，上方是排版讲究的大金额，颜色只给五类加一个灰色的「其他」。分组依据一换，柱图、明细表、环比瀑布一起变。给看云账单、算力成本的财务和负责人。
出处：AWS Cost Explorer（https://aws.amazon.com/aws-cost-management/aws-cost-explorer/）；Vantage（https://www.vantage.sh）；Kubecost（https://www.kubecost.com）。

## 一眼认出（不能改）
- 米色底，无卡片无阴影，靠留白和细线分区
- 左上大号衬线金额，「¥」和「万」用小一档的字
- 一张按天堆叠的大柱图，色块只有 5 色 + 灰色「其他」
- 「分组依据」胶囊切换（部门 / 厂商 / 资源类型 / 项目）
- 柱顶红色感叹号标出异常日，点开有说明
- 环比瀑布：上月合计 → 各项增减 → 本月合计，上升红、下降青
## 颜色
- 底 `#f6f3ec`，字 `#23211c / #5f5b51 / #8f8a7d`，线 `#ddd8cb`
- 类别：青 `#0f6b6b`、琥珀 `#d99a2b`、朱红 `#d8553c`、靛蓝 `#3d5a9b`、紫 `#8a4f9e`、其他灰 `#c3bdae`
- 红色同时用于「上升」和「异常」，青色用于「下降」
## 字体
- Fraunces 做金额，Noto Serif SC 做标题和「万」，Instrument Sans + Noto Sans SC 做正文
- 数字用 `tabular-nums`
## 真图怎么处理
- 不用照片
## 动效
- 载入时大金额 0.9s 计数上升，柱子按日期依次生长（每根错开 14ms）
- 切分组依据，柱图重新长出一遍
- 筛选标签 200ms 弹入
## 组件
- 顶栏：字标、页签、账期
- 汇总：大金额 + 环比、日均、峰值三个小数字
- 分组依据胶囊、图例（可点击隐藏某类）、柱图悬停提示
- 异常标记 + 说明浮层（列出贡献最大的三项）
- 明细表（无斑马纹，仅下划线）、可删除的筛选标签、导出 CSV
## 学什么交互
- 切分组依据，主图、明细、瀑布同时变 → 同一份数据换视角，不跳页 → 费用明细页顶部放「按部门 / 供应商 / 资源类型 / 项目」，下面的图表和表格联动。
- 点柱子里的一段，表格就筛到这一段，并生成可删的标签 → 筛选条件可见、可单独去掉 → 点「某部门 10 月 8 日」，下方按资源类型拆开，标签里能分别删日期和部门。
- 颜色只给前 5 类，其余归「其他」 → 图例读得完，颜色不会多到分不清 → 资源台账按型号分布，只上色前 5 个型号。
- 环比瀑布纵轴不从 0 起，并在角上写明起点 → 几万的变化在几百万的总额里才看得见 → 月度账单对比，告诉领导增量来自哪几项。
- 异常点直接标在图上，点开写原因和贡献最大的几项 → 不用先去查明细再回头 → 费用突增日打标记，浮层里给出「+¥xx」的前三名。
## 换到别的东西上
- 适合：云账单、算力成本、预算执行、用量对账
- 不适合：需要同时比较十几类的图
## 容易做坏
- 类别超过 6 色，图例和柱子都读不清
- 金额和单位一样大，重点就散了
- 瀑布图纵轴不写起点，增量被夸大
- 每块区域都加白卡和阴影，就变成普通后台

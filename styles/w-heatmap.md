# 占用方块图（w-heatmap）
深灰底上满屏嵌套的矩形：部门包着项目，项目包着作业，面积是卡数或费用，颜色是利用率或空闲天数（红低绿高）。点方块放大下钻，顶部面包屑回退。给要在一屏里找出「哪里占着卡不干活」的运营和负责人。
出处：Finviz 股票热力图（https://finviz.com）；Datadog Host Map（https://www.datadoghq.com）。

## 一眼认出（不能改）
- 整屏都是矩形，没有留白和卡片
- 每个部门有一条细标题条，里面写名称、卡数、加权利用率
- 红到绿的发散色阶，中间是灰，没有黄色
- 方块里的字号跟面积走，大块的名字很大，小块只剩一行小字或不写
- 方块之间只有 1px 深色缝
- 底栏是离散色阶图例 + 当前范围的合计
## 颜色
- 底 `#151618`，条 `#1b1c1f`，线 `#2c2e33`
- 色阶节点 0 `#c4343c`、28 `#8e383e`、52 `#484a52`、76 `#2c7a58`、100 `#1ca668`
- 搜索命中描边 `#ffe14d`
## 字体
- Inter + Noto Sans SC；方块里的数字和提示卡用 JetBrains Mono
- 方块名称粗体，数字行 62% 字号
## 真图怎么处理
- 不用照片
## 动效
- 开场：方块从中心依次散开到各自位置，约 1.2s
- 下钻：新层的方块从被点方块的位置放大到各自位置，旧层淡出
- 回退：旧层的方块缩回到它在上一层的位置，上一层淡入
- 切面积或颜色：方块滑到新位置并渐变到新颜色
- 搜索命中：黄色描边闪两下后常亮
## 组件
- 顶栏：字标、面包屑、搜索框、面积切换（卡数/费用）、颜色切换（利用率/空闲天数）
- 方块：部门标题条、项目小标题条、作业方块
- 悬停详情卡：名称、路径、卡数、利用率、空闲天数、月费用、负责人、利用率条
- 固定详情卡：点作业方块后在右上角固定，含处理建议
- 底栏：当前层合计、色阶图例、快捷键提示
## 学什么交互
- 面积和颜色各自独立切换 → 同一个布局可以回答「谁占得多」「谁用得差」「谁最贵」三个问题 → 放到「资源概览」：面积选费用、颜色选利用率，最大的暗红块就是该先查的部门。
- 下钻时方块从原位置放大，面包屑可回退 → 用户始终知道自己在哪一层，不会迷路 → 放到「物理机列表」的分组视图：全公司 > 部门 > 项目 > 作业。
- 字号随面积缩放，放不下就不写 → 大块读得清，小块不乱 → 放到任何占比图：只给占比超过 3% 的块标名字。
- 搜索命中的方块闪一下，不在当前层就先跳到那一层 → 搜出来的结果一定看得见 → 放到「资源台账」搜索：输入作业名，自动展开到它所在的项目并闪烁。
- 色阶是红到灰到绿，灰色是「正常」 → 异常的红和健康的绿都醒目，正常的不抢眼 → 放到利用率、闲置天数类指标。
## 换到别的东西上
- 适合：GPU/CPU 占用、云账单构成、存储目录体积、告警分布
- 不适合：需要精确比较少数几个数值的场合
## 容易做坏
- 色阶用红黄绿三色，视觉噪声过大
- 每层都显示所有层级，小块文字挤成一团
- 切换指标时方块瞬间跳动，用户失去位置感
- 下钻动画与被点的方块对不上（新层从别处冒出来）
## 参考实现
`gallery/w-heatmap.html`：`squarify()` 布局，`layout()` 生成当前层的块和标题条，`render()` 按 key 复用元素做滑动，`go()` 下钻/回退/跳转动画，`doSearch()` 搜索与闪烁，`tipHTML()` 悬停详情，`ramp()` 色阶。

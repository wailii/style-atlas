# 构成主义（constructivist）

红黑两色、斜线构图、大箭头、圆形照片和放射线，所有东西沿斜线猛冲进来。

出处：lemo-opuscar 风格库 kino-montage（构成主义蒙太奇，https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/kino-montage/STYLE.md）。

## 直接抄

```css
:root { --paper:#ece2cc; --red:#d22e26; --ink:#121110; }
@import url("https://fonts.googleapis.com/css2?family=Russo+One&family=Noto+Sans+SC:wght@500;700;900&display=swap");
.tag { clip-path: polygon(0 0, 100% 0, 80% 100%, 0 100%); }   /* 平行四边形 */
```
```js
SLAM = "cubic-bezier(.9,0,.15,1.25)"   // 0.42s，沿 -18° / -9° 从 300~600px 外冲进来
thresholdCanvas(img, 400, 400, { cut:.6, ink:"#121110", paper:"#ece2cc" })
```

## 一眼认出（不能改）

- 只有红、黑、米色纸三种颜色
- 斜着的色带（−9°、−4°）、从一个圆心放射的线、粗箭头
- 照片是黑白剪影，装在圆里
- 平行四边形的标签和编号
- 动作是猛冲、急停，像宣传画动起来

## 颜色

- 纸 `#ECE2CC`，红 `#D22E26`，黑 `#121110`
- 不能改：三色

## 字体

- 数字和拉丁：Russo One；中文：Noto Sans SC 900
- 标题白字压在红色斜带上

## 底和纹理

- 噪点 multiply，像旧海报

## 真图怎么处理

- `thresholdCanvas(img, w, h, { cut: .6, ink: 黑, paper: 纸色 })` 切成两色
- 主图装进 10px 黑圈的圆里，慢慢转（40s 一圈）；小图也是圆

## 线和形

- 放射线：从圆心出发 14 条，粗细交替，每 3 条一条红
- 箭头：长条 + 三角，−18° 指向标题
- 斜带：整条红带旋转 −9°，比屏幕宽
- 编号：平行四边形（`clip-path: polygon(0 0,100% 0,80% 100%,0 100%)`），红黑交替

## 动效

- 猛冲：沿斜线方向从 300～600px 外冲进来，`cubic-bezier(.9,0,.15,1.25)`，0.42s，冲过头一点再停
- 放射线一条条画出去（每条间隔 30ms）
- 圆从 0 转着放大进来
- 列表文字用硬切出现（不淡入）
- 底栏指示块按 snap 缓动跳过去

## 组件

- 主按钮：红色喇叭；播放时声波一圈圈按 `steps(3)` 出现
- 头部：黑色斜带上写标题
- 主卡：放射线 + 圆形照片 + 巨大红色编号 + 箭头 + 红色斜带标题 + 黑色斜标签数据
- 列表：粗黑横线分行，左侧平行四边形编号，右侧圆形剪影；选中整行反黑
- 底栏：黑底，红色平行四边形指示块

## 换到别的东西上

- 网页：首屏一张宣传画；章节标题都斜着冲进来
- 视频：踩着鼓点斜向冲入、照片蒙太奇；声音用铜管齐奏、军鼓、打字机
- 活动海报、号召类内容最合适

## 容易做坏

- 斜线角度超过两种就乱
- 正文也斜就读不了——只有标题和标签斜
- 加第四种颜色

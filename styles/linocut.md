# 黑白木刻（linocut）

凸版印刷：整块是黑的，白是刀一道道挖出来的。刀痕两头尖、中间鼓，顺着形体走；大块亮处整片铲掉，边上留几道没铲干净的刀渣；墨没吃满的地方露出纸的白点；再套一块朱红版，故意没对准。像珂勒惠支的版画、1930 年代鲁迅倡导的新兴木刻。动作是做版画的三步：刻 → 滚墨 → 揭纸，揭开时图才翻成正的。

出处：灵感来自抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》里录屏的「The Notturno Experience」（红、纸白、黑墨三色，模型渲染成版画式的线刻）；语法学自 Linocut（https://en.wikipedia.org/wiki/Linocut）、Woodcut（https://en.wikipedia.org/wiki/Woodcut）、Käthe Kollwitz（https://en.wikipedia.org/wiki/K%C3%A4the_Kollwitz）的版画和 1930 年代的新兴木刻运动。

```js
// 刻版（carveJob）：亮度拉伸后——
dark = 0.20   // 以下整块留黑（偶尔 12% 一道 0.8px 细刀纹）
light = 0.84  // 以上整片铲掉，阈值上叠 ±0.08 的低频噪声 → 边不齐
// 中间调：每 4.2px 撒一个种子，沿「5px 模糊后亮度梯度转 90°」的方向往两头追 8～24px；梯度弱处用 -0.5±0.35rad 的缓变斜向场
// 刀宽 = 0.7 + (亮度-dark)/(light-dark) × 3.3，两头收尖：w × sin(π t)^0.55
// 亮底图（中位亮度 > 0.62）反过来刻：底留黑、主体刻白
// 红版：饱和度最高的 30%，3px 模糊再切；每印一张随机错位 (2～5, -1～-4)px，正片叠底压在黑版下面
// 墨：每张随机挖 0.22% 面积的小白点（0.4～2px）；版边不齐（每段 ±0.7px 抖）
// 时间线：0.15～1.25s 刻 / 1.3～1.75s 滚墨 / 1.85～2.6s 揭纸
```

## 一眼认出（不能改）

- 黑多白少：白是刻出来的，不是画上去的
- 刀痕两头尖、中间鼓，顺着形体走，越亮刀越宽
- 大片白里留几道没铲干净的刀渣，所有边都不齐
- 墨里有没吃上墨的白点、纸纹透出来
- 朱红第二版，和黑版错开几像素
- 刻版时是镜像的，揭纸后才是正的

## 颜色

- 纸 `#ECE4D2`（偏黄的宣纸）+ 纤维纹 + 颗粒
- 墨 `#17130F`（暖黑，不用纯黑）
- 朱红 `#C62A1E`：只做第二版色块、印章、选中标记
- 刻的过程里才出现：油毡版面 `#4A3F36`、刀口露出的浅色 `#B9A58A`

## 字体

- Noto Serif SC 900（标题、编号、印章字）/ 700 / 500（正文）
- 大字、黑块、粗线一律套 `#carved`（推边 + 白点）；小字和摘要只套 `#carved2`
- 编号用中文数字：壹（主图）、一二三四…（列表印章）

## 真图怎么处理

- `carveJob(img, W, H, opts)` 生成：一组刀痕（按「从上往下 + 一点随机」排序，方便逐刀刻出来）、挖空遮罩、红版遮罩
- `pull(job, seed)` 印一张：纸 → 红版（错位、带白点）→ 黑版（刻掉的部分挖空、带白点、版边不齐）。同一块版每次印都略有不同
- 主图右下角留一块黑、刻一个「壹」：刻版时它是反的，印出来才是正的
- 列表小图：同一套刻法缩小（间距 3.4、刀宽 2.4）；没封面的把 `DOODLE` 线条画成黑底白线再刻——就是一幅白线木刻
- 浅底封面（c1 logo 墙）会被反过来刻成黑底白图标；文字截图（c4）会刻成一行行白刀痕，认不出字，属正常

## 动效

- 刻：深色油毡版（镜像），刀痕从上往下一刀刀出现，亮处跟着一片片铲开（增量画，每帧只补新刀）
- 滚墨：一根黑色滚筒从上往下滚，滚过的地方没刻掉的面变成黑墨
- 揭纸：从左上角往右下斜着揭，揭口一道卷起来的纸边；揭开处是印好的正像
- 刻 / 墨 / 印 三个小标签跟着步骤反白
- 版面其他东西像盖章一样落下：`steps(4)`，先大一点、一顿、落定
- 再印一张：印次 +1，重新揭一次纸，红版位置和白点都换

## 组件

- 头部：大字「AI 热点」（推边 + 白点），后面压一块歪 0.6° 的朱红块（错版）；小字「新兴木刻 · 十月廿二 · 第一版」；右边「听」是黑圆版上刻一圈放射刀痕、中间朱红圆，播放时按 6 格一顿一顿地转
- 主图：印在纸上的一块版（版边不齐、纸边留白），下面「刻 墨 印」步骤 + 「印次 1 / 20」+ 朱红按钮「再印一张」
- 标题：黑版反刻（黑底纸色字），右上角朱红小印「壹」
- 数据：上下 4px 粗黑线、格间 3px 黑线，Serif 900 大数字
- 分节：两边粗黑线夹「其余七条」
- 列表：76px 小版画 + 左上朱红中文数字印章 + 标题 + 热度；点开摘要是一块黑版反白字，从左往右 `steps(5)` 印出来，标题变朱红
- 底栏：顶上一条粗黑刻线；选中项是一块黑版反白字 + 右上朱红小方块

## 换到别的东西上

- 网页
  - 首屏一幅大版画（整屏宽），滚动到这一节时按刻 → 墨 → 印播一遍；鼠标悬停卡片：那块版重新滚一次墨
  - 标题区黑版反刻；正文保持纸色底、Serif 正文，不套滤镜
  - 页与页之间用揭纸转场
- App
  - 主卡播完整三步（≤ 2.6s），其余小图只播「揭纸」；点击反馈是盖章（`steps(4)` 一顿）
  - 白点遮罩和推边滤镜很贵，只给大字和黑块，不要套在整页上
- Dashboard（图表、大数字、表格）
  - 柱状图：每根柱子是一块黑版，柱子里顺着柱子方向刻几道白刀痕（越高刀痕越多）；对比项用朱红版
  - 大数字：Serif 900 黑版反刻，或朱红印章框里的白字
  - 表格：粗黑刻线分隔（4px 外框、2.5px 行线），表头黑底纸色字；高亮行朱红印章标记
  - 折线：粗黑线 + 推边滤镜，节点是朱红方印
- 视频（镜头、转场、声音）
  - 镜头：俯拍工作台，刻刀特写 → 滚筒推过 → 揭纸的慢动作；或者一张版画里镜头慢慢推进到局部刀痕
  - 转场：揭纸（斜着揭开露出下一张）、滚筒滚过一屏换成新画面
  - 声音：刻刀划过油毡的「嚓嚓」、滚筒黏墨的「啪嗒」声、揭纸的撕拉声；配乐用木鱼、低音提琴、手风琴
- 海报设计
  - 原版语法：一张大图刻成黑白，加一块朱红版错位叠印，标题刻在黑块里反白；底部小字「某年某月 · 第几版 · 印次 x / 20」
  - 输出大图时刀间距按版面放大（4.2px → 印刷 1.5～2mm），白点也跟着放大
- 适合：人文、历史、社会议题、纪录片、出版、手工品牌、节日海报

## 容易做坏

- 用阈值二值图冒充木刻：没有刀痕方向，像复印件
- 刀痕方向乱：每刀都要顺着形体（亮度等高线）走，背景里也要成组平行
- 白多黑少、灰蒙蒙：浅底图要反过来刻
- 边太整齐、墨太均匀：像矢量图。边要推、墨要有白点、红版要错位
- 滤镜套在长段小字上：读不了。小字只轻推边
- 红色用多了：红只是第二版和印章，一屏不超过 15%

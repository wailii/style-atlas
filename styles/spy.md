# 间谍片头（spy）

60 年代电影片头：米色底、大块橙色、黑色粗条和圆环、剪影照片，所有东西踩着爵士鼓点硬切出现。

出处：lemo-opuscar 风格库 spy-titles（https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/spy-titles/STYLE.md）。

## 直接抄

```css
:root { --cream:#efe4c9; --ink:#151412; --org:#e4572e; }
@import url("https://fonts.googleapis.com/css2?family=Oswald:wght@500;700&family=Noto+Sans+SC:wght@500;700;900&display=swap");
/* 一拍 */ const BEAT = 240; /* ms，元素按半拍硬切出现 */
/* 黑条扫入 */ cubic-bezier(.8,0,.2,1) 520ms
```

## 一眼认出（不能改）

- 平涂的橙色大色块 + 黑色粗条、圆环、锯齿条
- 照片是黑色剪影压在橙色上
- 标题每个字角度、高低都不一样（剪出来的字）
- 出现方式是按鼓点硬切，不淡入
- 斜切的编号标签

## 颜色

- 米 `#EFE4C9`、黑 `#151412`、橙 `#E4572E`，没有第四色

## 字体

- 数字、英文、日期：Oswald 500 / 700，加字距
- 中文：Noto Sans SC 900，每个字随机 ±3px、±4.5° 的偏移

## 底和纹理

- 噪点 multiply，像胶片印刷

## 真图怎么处理

- `thresholdCanvas(img, w, h, { cut: .62, ink: 黑 })`，multiply 叠在橙色块上

## 动效

- 开场：4 根黑条从四边扫进来（0.52s），停在构图位置，然后淡出
- 之后每个元素按 0.12s（半拍）一个，`steps(1)` 硬切出现
- 橙色块从左擦开；锯齿条从右推入
- 常驻：节奏条每拍随机变高；圆环每拍轻轻一跳
- 播放键是眩晕螺旋，播放时 2.4s 一圈

## 组件

- 主按钮：橙色圆里一个黑色螺旋
- 主卡：橙色色块 + 剪影 + 黑圆环 + 锯齿条 + 大号黑色编号 + 标题（重点字橙色）
- 节奏条：一排黑橙相间的竖条 + 数字
- 列表：左侧斜切编号块（黑 / 橙交替）+ 标题 + 「热度 447 — 9 家」
- 底栏：黑底，橙色下划线 `steps(3)` 跳到当前项

## 换到别的东西上

- 网页：首屏就是片头；滚动到哪一节，那一节按鼓点硬切出来
- 视频：剪辑点全踩在鼓点上；声音用鼓刷军鼓、走动的低音提琴、铜管重音
- 适合：影视、音乐、活动、品牌片头

## 容易做坏

- 用了缓动淡入就不像了
- 加渐变、加圆角卡片
- `<i>` 默认斜体，记得改正

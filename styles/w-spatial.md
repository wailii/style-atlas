# 空间玻璃（w-spatial）
一张真照片铺满，几块磨砂玻璃窗悬在上面，大圆角、近大远小，鼠标一动整个空间带着视差轻轻转。窗口不贴边、不画分割线，内容全部用白字的不同透明度分层。适合做沉浸式的个人工作区，把今日概况、媒体、消息这类轻量信息摆在眼前。
出处：Apple visionOS（https://www.apple.com/apple-vision-pro/）。

// 视差：z 越大越近，动得越多，同时有一点点旋转

## 一眼认出（不能改）
- 背景是整张真照片，窗口是半透明磨砂玻璃，没有实色卡片
- 窗口圆角 36px 左右，内部卡片 22 到 26px，不出现直角
- 窗口大小不同，近的大、远的小，投影很深，边缘有一圈 1px 亮边加顶部高光
- 每个窗口底部居中一条小抓手，可以拖动整个窗口
- 所有文字是白色，靠透明度分主次（96% / 78% / 42%），没有彩色文字
## 颜色
- 底：照片本身，只压 18% 暖黑
- 玻璃 `rgba(255,255,255,.15)`，边 `.30`，内部卡片 `.10`，选中项 `.20`
- 文字白 96% / 78% / 42%；图形（环、柱、进度条）只用白，强弱靠透明度
- 没有彩色，状态不用红绿，用实心点与空心点区分
## 字体
- Inter + Noto Sans SC；标题 24px 600，正文 14 到 15px，数字用 tabular-nums
- 大数字 64px 700、字距 -0.04em
## 真图怎么处理
- 背景 `img/real/documentary-shore.jpg`（暖色日落海滩），放大 2% 并随视差平移，左下角标注摄影师
- 媒体窗口封面用 `img/real/satellite-harbor.jpg`，圆角 24px，旁边标「示意图 · 摄影师名」
- 照片要有明暗层次，玻璃才有东西可模糊；纯色或过亮的照片会让白字发虚
## 动效
- 入场：三个窗口间隔 220ms 依次淡入 800ms
- 视差：鼠标位置插值 7% 每帧，近处窗口移动更多
- 抓手拖动：窗口抬起，阴影变深、略放大
- 环和柱：切到概况时重新长出来，1.1s 缓出
- 悬停：按钮背景提亮，一块柔光跟着指针走
## 组件
- 概况窗口：标题与日期、三个进度环、七日柱状图（悬停读数）、待办三条
- 窗口左侧悬浮的标签栏（概况 / 日程 / 费用），悬停出现文字标签，切换时内容淡入
- 媒体窗口：封面、标题、上一首 / 播放暂停 / 下一首、可点击跳转的进度条
- 消息窗口：头像圆、未读点、选中高亮，底部详情和「回复」
- 玻璃按钮：圆角胶囊，1px 亮边
## 学什么交互
- 视差分层 → 深度本身就是层级，不用靠边框和色块 → 放到后台：概览页把「当前处理的工单」放近、「参考信息」放远，不用再加彩色标签区分主次。
- 竖向悬浮标签栏 → 标签不占窗口内容的高度，也不挡内容 → 放到后台：资源详情页把「基本信息 / 费用 / 变更记录」放在窗口侧边，悬停才出文字。
- 白字三档透明度 → 不增加颜色就能分三层信息 → 放到后台：费用明细里金额 96%，部门名 78%，更新时间 42%，不再靠灰色和加粗各凑一套。
- 抓手拖动窗口 → 工作区布局归使用者 → 放到后台：值班看板让使用者把告警、队列、日志窗口自己摆位置。
## 换到别的东西上
- 适合：个人工作区、车机或大屏的信息面板、AR / VR 界面原型
- 不适合：密集表格和长文阅读，玻璃上的细字会糊
## 容易做坏
- 窗口之间没有大小和投影差别，看不出深度
- 照片太亮或太花，白字读不清
- 悬停柔光常驻显示，变成装饰
- 视差幅度过大，窗口像在晃，字跟着发虚
- 给玻璃加彩色边或彩色文字，空间感就没了

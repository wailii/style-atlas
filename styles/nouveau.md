# 新艺术（nouveau）

1890 年代巴黎的 Alphonse Mucha：主角背后一个大圆光环，光环是一圈圈装饰带（小圆点、分格、玫瑰色内圈）；鞭线（whiplash）——长长的 S 形曲线末端一卷——像头发、藤蔓一样甩过光环；拱形画框，边上一串小花；颜色是压低饱和的鼠尾草绿、赭黄、灰玫瑰、奶油，所有形状都描一圈粗的深褐轮廓。安静、柔、贵。

出处：抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》录屏里的「The Notturno Experience」——立柱之间那扇大圆窗把人物框成光环的那一幕，这里取它「圆窗即光环」的一支，回到源头：Alphonse Mucha 的招贴与装饰版画（https://en.wikipedia.org/wiki/Alphonse_Mucha）和新艺术运动（https://en.wikipedia.org/wiki/Art_Nouveau）。

## 一眼认出（不能改）

- 主角背后一个大圆光环，光环本身是装饰：点圈、分格带、玫瑰内圈，都带轮廓
- 鞭线：S 形长曲线末端打卷，甩过光环；藤蔓上长叶子、开八瓣花
- 拱形画框，框上一串四瓣小花；整页再套一圈双线边框
- 低饱和四色：鼠尾草绿、赭黄、灰玫瑰、奶油；没有纯黑、没有荧光色
- 一切都有粗的深褐轮廓，里面平涂
- 字是有机的：Smythe 的细高拉丁字 + 站酷小薇的柔衬线中文

## 颜色

- 纸 奶油 `#F3E8D0`、羊皮纸 `#E6D3AB`
- 主色：鼠尾草 `#A9B594`（深 `#6B7B5F`）、赭黄 `#C6973F`、灰玫瑰 `#D69E8F`（深 `#A8605A`）、灰青 `#6F8F8B`
- 轮廓 深褐 `#3B2A20`；次要文字 `#7A6650`
- 强调只用深玫瑰（标题关键词、刊名 AI）；不用红
- 唯一允许的「光」：光环里一圈半透明羊皮纸色

## 字体

- 拉丁、数字、罗马数字：Smythe（新艺术招贴字，细高、末端有弯）
- 中文标题：ZCOOL XiaoWei（站酷小薇，柔衬线）；正文 Noto Serif SC 500 / 600，关键词 900
- 字距宽松（中文标题自带疏朗），不压、不斜、不加投影

## 真图怎么处理

- `muchaCanvas()`：缩 1/3 再放大去细节 → 饱和度压到 0.7 → 按 9 色调色板取最近色 → 5×5 众数滤波两遍（碎点并进大块，像手画的平涂）→ 只在明度差得开的色块之间描深褐粗线（里面的过渡不描）→ 叠一层 12% 羊皮纸色
- 主卡：结果裁成正圆放在光环正中，外面紧贴 3.2px 深褐轮廓
- 列表：同样处理成小圆章（`line: 2.2`），外套玫瑰环
- 调色板里不放黑褐：暗部落到深青、墨绿、深玫瑰，画面才不脏

## 动效

- 拱框从底部两端沿着边描上去（stroke-dashoffset 1.5s），框上小花随后淡入
- 光环一圈圈画出来：每圈描线错开 0.16s，填色同时淡入；装饰带转 40° 落定
- 真图在圈里从模糊里浮现（blur 6px → 0，1.3s）
- 藤蔓沿曲线长出来（1.5s），叶子和花在藤长到它那里时才绽开（缩放 0 → 1，轻微回弹）
- 文字淡入：刊名字距从 .3em 收拢、模糊变清；分隔鞭线描出来
- 常驻：光环外两圈各自慢慢转（140s 一圈，反向）
- 节奏：慢、柔，缓入缓出；不硬切、不大弹跳
- 点「听」：花瓣环开始转（6s 一圈），光环转快到 9s 一圈

## 组件

- 头部：刊名（Smythe「AI」深玫瑰 + 小薇「热点」）+ 下面一条带卷须的鞭线 + 小字期号；右边花瓣环勋章按钮「听」
- 主卡：拱形画框（深褐 + 赭黄双层边 + 一串小花）→ 鼠尾草底 + 竖向细条纹 → 大光环 + 圆形真图 → 两根鞭线甩过光环 → 底部六根花茎开花 → 叶形两端的米色铭牌写编号和数字
- 标题区：居中小薇标题 + 中间一朵小花的鞭线分隔 + 一行摘要 + 三个数（Smythe）
- 列表：小圆章（真图或线条图标）+ 左上赭黄小圆编号 + 标题；行间一条细线，中间一颗赭黄小圆结；展开块是叶形角（右上、左下圆角 22px）
- 底栏：羊皮纸底，顶上一排小拱；选中项背后升起一枚玫瑰色圆章（带两圈环）

## 换到别的东西上

- 网页：
  - 首屏：左文右图 5:7，右边一个占屏高 80% 的拱形框，里面大光环 + 主角；左侧标题 Smythe 120px
  - 两侧边距里放竖向的花藤边框，滚动时藤往下长；章节之间用一根带花的鞭线分隔
  - 悬停：卡片光环慢慢转、外圈亮一点；链接下面长出一小段卷须
- App：
  - 光环只给主卡用一次；列表用小圆章 + 细分隔，别每行都画花
  - 页面切换：淡入淡出 + 轻微缩放；加载：一圈点慢慢点亮成环
- Dashboard（图表、大数字、表格）：
  - 大数字：Smythe 48px 以上，放在一枚圆章或叶形铭牌里，下面一根小鞭线
  - 环形图天然合适：画成光环——每个分段是装饰带里的一格，用赭黄、玫瑰、鼠尾草、灰青四色，格与格之间描深褐线
  - 折线：2.4px 深褐线，线下填半透明鼠尾草；数据点是小八瓣花
  - 表格：没有竖线，行间细线 + 中间小圆结；表头用小薇，数字用 Smythe
- 视频（镜头、转场、声音）：
  - 镜头：慢推、慢摇，主角始终在光环中心；藤蔓、头发一直轻轻飘
  - 转场：光环像光圈一样收拢成一点再张开成下一个场景；或花藤从画面边缘长进来把画面盖住
  - 声音：竖琴、弦乐、八音盒；藤蔓生长配很轻的沙沙声，花开配一个高音钟片
- 海报设计：
  - 竖长画幅（1:2.5 左右），上面拱形 + 光环 + 主角，下面一块铭牌写标题，四周花边框
  - 文字也要「长在」装饰里：标题放在横带或铭牌上，不要直接放在空白处
  - 只用四个低饱和色 + 深褐轮廓；要「贵」就加一点真金（赭黄换成烫金）

## 容易做坏

- 轮廓用纯黑或太细——新艺术的线是深褐、粗、圆润的
- 颜色太饱和（正红、宝蓝、荧光绿）会变成廉价贴纸
- 鞭线画成规则波浪：要有长有短，末端一定要卷起来
- 光环只是一个纯色圆——它必须有层次和装饰
- 和装饰艺术混了：新艺术是曲线、植物、柔；装饰艺术是直线、阶梯、几何、对称
- 动作太快或弹跳太大

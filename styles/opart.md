# 线网幻视（opart）

图只用平行线画：线宽 = 暗度，线还顺着暗度轻轻偏一点，整片带一点波浪——像钞票上的线网雕刻，又像 Bridget Riley 的波浪条纹。字靠线换方向显出来（潜影），两层线叠在一起出摩尔纹，一直在动。黑白，最多加一种颜色。招牌动作是「滴落溶解」：画面拆成竖条，每条往下拉长、坠落，再从上面滴回来拼好。

出处：灵感来自抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》里录屏的「The Notturno Experience」（背景是波浪竖线网，转场时画面碎成竖条往下滴、拉长）；语法学自 Op art（https://en.wikipedia.org/wiki/Op_art）——Bridget Riley 的波浪条纹、Victor Vasarely 的线变形、钞票的线网雕刻和潜影，以及 Scanimation（栅条遮罩动画）。

## 直接抄

```css
@import url("https://fonts.googleapis.com/css2?family=Archivo:wdth,wght@62..125,400..900&family=Noto+Sans+SC:wght@500;700;900&display=swap");
:root { --paper:#f7f5ef; --ink:#0b0b0b; --acc:#0038ff; --mute:#6d6a63; }
.x { font-family: "Archivo"; font-stretch: 125%; font-weight: 800; }     /* 加宽无衬线：数字、编号 */
/* 文字进场：竖线遮罩一条条变宽 */
@property --w { syntax: "<length>"; inherits: false; initial-value: 0px; }
.lr { mask: repeating-linear-gradient(90deg, #000 0 var(--w), transparent var(--w) 5px); animation: lines .6s steps(8, end) both; }
@keyframes lines { from { --w: 0px; } to { --w: 5px; } }
/* 扫描动画栅条：4 帧交错，缝 1.25px，一拍挪一缝 */
.mask { background: repeating-linear-gradient(90deg, var(--ink) 0 3.75px, transparent 3.75px 5px); transform: translateX(calc(var(--f) * 1.25px)); }
```

```js
// 线网：每条线沿自己的方向逐像素采暗度 D = (1-亮度)^1.1（亮度先按 2%～98.5% 拉伸）
pitch = 4.5;  width = 0.35 + D * (pitch * 0.95 - 0.35);
x = x0 + 1.1 * sin(y * 0.045 + x0 * 0.021) + (D - 0.5) * pitch * 0.35;   // 波浪 + 随暗度偏移（浮雕感）
// 每条线是一个多边形（左边一串点、右边一串点倒回来），全部线合成一个 Path2D 填一次
// 字形 / 编号里：同一张图改用横线画（只换方向）
// 摩尔纹：蓝色同心圆，间距 4.7、线宽 0.8、70% 不透明，圆心慢慢漂，正片叠底压在竖线上
// 滴落：竖条宽 9px；每条延迟 0～0.45、拉长系数 0.6～2.2
//   进：滴落前沿 = H × e × 1.25，条带拉长 1 + (1-e) × 2.4k，前沿挂一滴墨（椭圆）
//   出：下坠 e² × H × (0.9 + 0.5k)，拉长 1 + 1.8ek
```

## 一眼认出（不能改）

- 图里没有一块灰，深浅全靠平行线的粗细
- 线整片微微起波浪，像布纹在动
- 字和数字靠「线换方向」显出来：外面竖线、里面横线
- 第二层线（同心圆或斜线）叠出摩尔纹，一直在漂
- 转场是竖条往下滴、拉长、再落回原位
- 黑、白 + 至多一种颜色（这里是克莱因蓝 `#0038FF`）

## 颜色

- 纸 `#F7F5EF`，墨 `#0B0B0B`，只用一个强调色：蓝 `#0038FF`（摩尔纹层、关键词、选中项、按钮中心点）
- 灰 `#6D6A63` 只给小字说明，不出现在图里

## 字体

- Archivo 加宽（`font-stretch:125%`）800：编号、数字、标签全大写加宽字距
- Noto Sans SC 900（标题）/ 700（列表标题）/ 500（正文）
- 页面大标题不用字体直接写：画成线网潜影字（字外竖线、字内横线）

## 真图怎么处理

- `stretchedLuma(img, w, h)`：cover 裁切、0.7px 模糊、亮度按 2%～98.5% 拉伸
- `lineScreen(ctx, L, w, h, { pitch, dir })`：竖线（或横线）线网，线宽 = 暗度，带波浪和浮雕偏移
- 主图：竖线版 + 横线版各画一张，横线版只留「01」字形里、竖线版在字形里挖掉，拼成一张
- 小图：间距 3.2，单数行竖线、双数行横线；没封面的把 `DOODLE` 路径描粗当亮度图再压线网
- 浅底 logo 墙这类封面线网出来偏淡，深色有主体的封面（c2）最好看

## 动效

- 进场：头部潜影字竖条从上往下长出来；主图 1.7s 滴落进场；文字竖线遮罩 `steps(8)` 一条条变宽
- 常驻：潜影字里的横线一直往下滑（6px/s），字外竖线不动——字在「闪」；摩尔纹圆心慢慢漂；分隔带的波浪竖线一直流动
- 点主图：当前图 0.9s 坠落成竖条，下一张 1.3s 滴进来（四张封面轮换）
- 扫描动画：「听」按钮里是 4 帧声波环交错成的一张图，播放时栅条遮罩每 1/12 秒挪一缝，环一圈圈往外扩
- 列表小图：错开滴落进场，点开那一条重滴一次

## 组件

- 头部：小字标签行（LINE SCREEN № 01 / 日期 + 蓝方块）+ 线网潜影大字「AI 热点」+ 右边扫描动画按钮（上半是交错图 + 栅条、下半「听」，播放时反白）
- 主图：2px 黑框，线网封面 + 摩尔纹层，右上黑底标签「LPI 21 · 点按换图」（LPI 按线距真算：96 ÷ 4.5），下方说明「封面 → 线宽 = 暗度」和「COVER 1/4」
- 标题：黑字，关键词蓝色；摘要一段
- 数据：三格，上下 2px 黑线、格间 1px；加宽大数字 + 线宽渐变条（数值多大，线粗到哪；后面是细线）
- 分隔带：30px 高的莱利式波浪竖线，贯穿全宽
- 列表：上下 1px 线分行；左 78px 线网小图 + 角上编号；标题 + 线宽条 + 热度；展开摘要用竖线遮罩长出来，标题变蓝
- 底栏：顶上一排中间粗两头细的竖线；选中项蓝色 + 下面一排短竖线

## 换到别的东西上

- 网页
  - 首屏整屏线网大图，鼠标位置是摩尔纹层的圆心（跟手漂）；滚动时线网整体波浪相位跟着走
  - 换图、换页都用滴落溶解；悬停卡片：线网间距瞬间变密一档
  - 大标题全做潜影字；正文区保持白底，线网只给图和标题
- App
  - 主卡一张线网图 + 一个扫描动画按钮就够；列表小图线网间距 ≥ 3px，不然在手机上糊成灰
  - 点击反馈：被点的东西线方向转 90°（竖变横）一下再回来
- Dashboard（图表、大数字、表格）
  - 柱状图：柱子用竖线填，线宽 = 数值；对比两组时一组竖线一组横线
  - 面积图 / 热力图：用线网画，线宽表示强度，不用颜色
  - 大数字：潜影字或加宽 800；表格行间用 1px 线，选中行线网底纹
  - 变化：数据更新时那一格滴落重绘
- 视频（镜头、转场、声音）
  - 镜头：几乎不动，靠线网自己在动（波浪、摩尔纹漂移、栅条扫描）
  - 转场：竖条滴落溶解（出 → 进）；或栅条遮罩一推，旧画面换成新画面
  - 声音：极简电子、高频脉冲、和栅条移动同步的滴答；滴落时一个下行的滑音
- 海报设计
  - 一张人像或产品压成大线网（间距按印刷 2～3mm），标题用潜影字；加一层蓝色同心圆做摩尔纹
  - 丝网印刷、单色或双色印都合适
- 适合：音乐、艺术展、时装、科技发布会、需要「晕眩感」的活动主视觉

## 容易做坏

- 线太细太密：屏幕上变成灰，摩尔纹也出不来（间距 ≥ 4px 起步）
- 用 CSS 渐变条纹假装线网：线宽不随图变，看不出图
- 加第二、第三种颜色：马上变成普通海报
- 摩尔纹层太实：盖住底图。强调色线宽 ≤ 1px、透明度 ≤ 75%，字形里挖掉
- 滴落所有竖条同时动：像幕布拉下来。每条要错开时间、拉长系数也不同
- 整页都铺线网：读不了字。正文永远在白纸上

# 原相机（rawcam）

不修图的手机相机：闪光灯直打，主体发白、背景掉进暖黄的暗里，手一抖画面就歪了一点；角上是前置摄像头拍的自拍小窗（双摄同时拍），右下角是橙色的 LED 日期，像老傻瓜机打在底片上的那种。配文不是排版出来的，是备忘录里随手敲的。2026 年「真实感」潮流：照片 dump、双摄、日期戳、备忘录截图。

出处：图鉴原有 60 种全是插画、版画、复古界面这类风格化画法，缺一组看起来像真照片、真光线、真镜头的风格，于是加了「写实 · 影像」组（61–70），这是其中一种。画面语法来自真实的用法：BeReal（https://bereal.com ）前后摄同时拍、小窗压在大图角上、点小窗互换；带日期机背的胶片傻瓜机打在画面右下角的橙色七段数码日期，以及模仿它的复古相机 App；社交平台上「photo dump」式不修图的闪光灯照片；用 iPhone 备忘录截图当配文的发帖习惯。参考页的照片全部来自 Unsplash（Unsplash License），经 Hugging Face 上的镜像数据集 `wtcherr/unsplash_5k`（https://huggingface.co/datasets/wtcherr/unsplash_5k ）取用，EXIF 来自每张图旁边的 `.json`：Erik Mclean（https://unsplash.com/photos/-MTyujylR6I ）、Marina Montoya（https://unsplash.com/photos/JIMpO5hHezA ）、Aurelia Borzin（https://unsplash.com/photos/SU9ew9mJoSU ）、Nathan Dumlao（https://unsplash.com/photos/ozVQrfENFOs ）、Spencer Davis（https://unsplash.com/photos/wvnSt-oYIB4 ）、Toa Heftiba（https://unsplash.com/photos/mtuYqjDzaXM ）。这些图是单反 / 无反拍的，参考页在浏览器里把它们处理成手机直出的样子，并在图下写明真实的相机参数；都标「示意图」，与新闻事件无关。

```js
// 闪光灯直打（canvas 逐像素，gallery/s-rawcam.html 的 flashRaw），在线性空间里做：
// 1) 画面先转 -2.4°（手抖），放大到填满
// 2) d = 到闪光中心的距离 / (对角线 × fr × .5)，f = exp(-1.1 d²)；增益 = .09 + 3.2 f（环境欠曝，闪光补上）
// 3) 白平衡：闪光处 r × .95、b × 1.06（中性偏冷），远处 r × 1.14、b × .8（暖色室内光）
// 4) 手机色调映射 v(1 + v/1.6)/(1 + v)，到 1.6 就顶白；饱和度 × 1.16
// 5) 过度锐化：x + (x - blur(x, W/500)) × .7；暗部彩色噪点 ±.05 × (1 - L)²
flashRaw(img, w, h, { fo: [.5, .5], flash: [.5, .4, .5], tilt: -2.4 });
// 前摄：镜像 + 1.2° + 和 blur(W/90) 版各一半（磨皮）+ 暖色 soft-light + 几乎不锐化
// LED 日期：七段数码管，斜 .12，四层描边：#ff3d00 粗光晕(blur .35h) → #ff7a12 → #ffc46b 芯 → #fff1c9 细芯
stamp(ctx, "'26 10 22", 右边x, 底边y, 16);
```

## 一眼认出（不能改）

- 主图是**闪光灯直打**的样子：中间亮、发白偏冷，四周掉进暖色的暗里，有手机式的锐化白边和暗部彩噪
- 画面歪 2～3°（手抖），不是摆正的
- 左上角压一个**前摄自拍小窗**：黑边圆角，镜像、偏软偏暖；点它前后互换
- 右下角**橙色 LED 日期**：七段数码管、斜体、发光；写的是热榜日期 `'26 10 22`
- 配文是**备忘录**：白卡、黄色「‹ 备忘录 / 完成」、居中灰色日期、系统字、黄色闪烁光标
- 列表是备忘录清单：黄色圆圈能勾，右边是方形的原相机小图

## 颜色

- 底 `#F2F2F7`（系统分组底），卡片 `#FFFFFF`，正文 `#000`，次要 `#8E8E93`，分隔 `#E3E3E8`
- 唯一强调色：备忘录黄 `#E0A000`（返回、完成、光标、勾选、底栏选中）
- LED 橙：光晕 `#FF3D00`、主体 `#FF7A12`、芯 `#FFC46B`、最亮 `#FFF1C9`——只用在日期戳
- 照片的颜色交给闪光：主体冷白、背景暖黄

## 字体

- 全部系统字：`-apple-system, Inter, Noto Sans SC`
- 大标题 32px 800（像系统大标题）；备忘录标题 21px 700、正文 15.5px 400；清单 15.5px 400；读数 12.5px 灰
- 日期戳不是字体，是 canvas 画的七段数码管
- 不用衬线、不用等宽、不用装饰字体——这是一部手机，不是一本杂志

## 真图怎么处理

- 选图：狗、朋友、聚会、吃喝、夜里的雪、随手的日常；近景、有一个明确的主体；风景大片、精修人像不对
- 后摄全部过 `flashRaw`：`flash` 的中心放在主体脸上，`fr` 越小背景越暗；本来就很亮的白墙会剩中灰，正常
- 前摄挑一张笑脸近景，过 `frontCam`（镜像、磨皮、暖）；大小两套都提前处理好，点小窗互换时直接换
- 原图多是单反拍的，背景虚化会比手机大——尽量挑景深深一点的；在图下写明真实相机参数，不假装是手机拍的
- 日期戳写内容的日期（这里是热榜日期），在页脚注明「不是拍摄日期」
- 每张图下写「示意图 · 后摄 X · EXIF / 前摄 Y · EXIF · Unsplash」；小图写「示意图 · 摄影师」

## 动效

- 开场就是拍照：白闪一下（0.52s，15% 处最亮）→ 主图从 1.12 倍、过曝发白落回（0.65s）→ 前摄小窗弹出（0.52s，过冲 1.06）→ 日期戳像灯管一样闪一下再亮稳
- 备忘录逐字打出近况（38ms 一个字），后面一个黄色光标一直闪
- 卡片上浮 10px 淡入；勾选圆圈：填黄 + 白勾从 .4 倍弹出（cubic-bezier(.3,1.6,.5,1)）
- 点相机按钮：再闪一次、再拍一次；点前摄小窗：前后互换，小窗按下回弹

## 换到别的东西上

- **网页 / 落地页**
  - 首屏是一组「photo dump」：3～5 张原相机照片散落排开（每张歪 1～4°），一张带前摄小窗，一张带 LED 日期；标语写成备忘录截图
  - 正文像一篇备忘录：系统字、清单、黄色光标；按钮就是备忘录里的黄字
- **App**
  - 参考 `gallery/s-rawcam.html`：双摄卡 + 备忘录 + 清单
  - 适合社交、日记、打卡、相册、活动回顾；「发布」就是相机快门（白闪 + 落定）
- **Dashboard**
  - 系统分组底 + 白色圆角卡，每张卡像一条备忘录：标题、灰色时间、正文数字
  - 大数字：系统字 800、黑色；变化写成一句话（「比昨天多 12」），不用红绿箭头
  - 图表：简单的系统样式——折线 2px 黑、填充 8% 黄；柱状图圆头、选中的一根黄色；不加网格线
  - 表格做成清单：左边圆圈（完成 = 黄）、中间名字、右边数值灰色
  - 配一张原相机照片当「今日一张」，带 LED 日期
- **视频**
  - 镜头：竖屏、手持、有点晃；闪光灯照片快速连翻（每张 0.3～0.6 秒），中间插前后摄互换的一下
  - 转场：白闪 + 快门声；日期戳在每张照片上都亮着
  - 字幕：备忘录截图式的白卡逐字打出来；声音：真实环境声、笑声、快门、手机键盘声，最多一段很轻的流行歌
- **海报设计**
  - 一张闪光灯原片占满，歪一点；左上前摄小窗，右下 LED 日期；下面贴一张备忘录截图当文字
  - 不加设计字体和装饰，越像随手截图越对

## 容易做坏

- 把照片调得好看（柔光、低反差、电影色）——这个风格要的是「没修过」的硬闪光
- 闪光衰减做成 CSS 径向渐变压在图上——要在线性空间里乘到像素上，高光要爆
- LED 日期用普通数字字体、不发光、放在左上，或者写成拍摄日期却没有依据
- 前摄小窗没有镜像、没有黑边，或者和主图一样清晰锐利
- 备忘录做成花哨卡片：加阴影、换字体、换颜色；黄色以外再加强调色
- 不写摄影师和真实相机参数，或把示意图当新闻现场

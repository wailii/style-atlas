# 意式招贴（affiche）

1900～1920 年代意大利、法国开胃酒招贴：一整块饱和的平色底，一个活蹦乱跳的人物或一只酒瓶从黑里冲出来，几乎不画背景；手绘大字带一层错开的立体投影；石印版只有五六种油墨，颜色压成平块，纸上有石板斑驳。瓶子是主角，开瓶、溅泡、柠檬皮绕瓶身是招牌动作。

出处：抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》录屏里的「The Notturno Experience」（意大利开胃酒品牌的滚动 3D 故事页：朱红 + 纸白 + 黑、三色酒瓶、往马天尼杯里倒酒），这里取它「开胃酒品牌 + 酒瓶当主角」的一支，回到招贴的源头：Leonetto Cappiello 的招贴语法（https://en.wikipedia.org/wiki/Leonetto_Cappiello）——黑底上一个亮色形象、一句品牌名，Campari 1921 年那张小丑缠在一圈橙皮里；石印工艺（https://en.wikipedia.org/wiki/Lithography）。

## 一眼认出（不能改）

- 一整块饱和平色底（铬黄），没有渐变、没有照片背景
- 主视觉是黑底上一个亮色主角（这里是朱红酒瓶），大、斜、正在动，边缘干净
- 手绘大字：粗胖的意大利体拉丁字 + 900 粗黑中文，朱红字 + 黑色斜向立体投影，略斜着放
- 只有五六种油墨：黑、米、朱、铬黄、翠绿、群青；真图也压进这几色
- 招牌动作：开瓶——塞子飞出、泡沫一粒粒溅开、柠檬皮绕瓶身一圈圈缠上
- 纸上有石印的斑驳和颗粒

## 颜色

- 底 铬黄 `#F2AE1C`；招贴底 墨黑 `#17110D`；主色 朱红 `#E2361D`；纸 米 `#F8ECD0`
- 点缀：柠檬黄 `#FFD92E`（柠檬皮、热度章）、翠绿 `#1D7A4B`（瓶封、缩略图底）、群青 `#1F4F9C`（缩略图底）
- 一屏最多一块大黑；朱红只给主角和要点，正文一律墨黑
- 可以整套换底色（朱红底配黑瓶、翠绿底配朱瓶），但永远是「一块平色底 + 一块黑」

## 字体

- 拉丁大字、编号：Shrikhand（胖、意大利体、像招牌画师手写）
- 小标签、数字章：Alfa Slab One（粗板衬线，字距拉开）
- 中文：Noto Sans SC 900，标题 `skewX(-8deg)` 跟着拉丁字一起斜；正文 500
- 大字永远带立体投影，小字永远不带

## 真图怎么处理

- `litho()`：缩 1/3 再放大（去掉细节，色块才像石版）→ 取四边像素的中位色当背景，色差小于 46 的挖掉 → 饱和度拉到 1.5 倍再按 6 色取最近色、不抖动 → 主体外缘描 2px 墨线 → 整张错开 1.2px 再压一层淡墨（套印不准）
- 主卡：结果贴在酒瓶的酒标上，背景换成酒标米色——真图是「产品上的那张标」，不是一张照片
- 列表：挖掉背景的剪影贴在一枚彩色圆章上（`soft: 5` 更块状），圆章带 4px 实心黑投影
- 没封面就用 `DOODLE` 线条图标，米色粗线画在圆章上

## 动效

- 黑底先「压」下来：clip-path 从下往上 0.52s（石印第一版是黑）
- 大字一笔刷上去：遮罩从右往左推 0.6s，词与词错开 0.26s
- 瓶子从黑底下面跃出来：位移 + 转 38° + 缩放 0.7，`springCurve(170, 11)` 过冲后落定
- 开瓶：塞子沿弧线飞到右上角转一圈；34 粒泡沫沿抛物线往右上冲、往右下落，每粒延迟随机 0～0.26s
- 柠檬皮沿螺旋中线一圈圈缠上去（遮罩描边 1.1s）
- 常驻只有一个：瓶子 3.2s 一个来回轻轻晃
- 点击反馈都是「弹」：编号转 -10° 放大、展开块从 0.6 倍弹到 1、底栏图标往上一跳

## 组件

- 头部：左边斜放的手绘大字刊名 + 一行字距拉开的小标签；右边皇冠瓶盖按钮（21 齿、朱红、黑芯、「听」），点了瓶盖弹起转一圈、塞子再开一次
- 主卡：一张招贴——米色纸边 + 墨框 + 实心错位投影；左上 N°1，左侧柠檬黄热度圆章，中间酒瓶，底部关键词当品牌名（米色字朱红投影）
- 标题区：900 粗黑标题，关键词朱红；三个黑底/朱底小方签放数字
- 列表：「今日酒单」；每行 Shrikhand 大编号（带投影）+ 标题 + 彩色圆章缩略图；行间 3px 黑线；展开是一块黑底米字、朱红实心投影
- 底栏：黑底，顶上 5px 朱红线；选中项是一块手撕形状的柠檬黄色斑 + 朱红错位投影

## 换到别的东西上

- 网页：
  - 首屏就是一张招贴：满屏平色底，左侧 120px 以上的手绘品牌字，右侧 70% 高的黑块里主角冲出来、出框半个身位
  - 滚动驱动：每滚一屏换一种底色（铬黄 → 朱红 → 翠绿），主角跟着换一个动作（跳、倒酒、开瓶）；底色是硬切，不渐变
  - 悬停：卡片投影从 4px 加到 8px、字往左上提 2px；按钮像瓶盖一样转半圈
- App：
  - 主卡永远是一张「小招贴」，一个主角一句话；列表用大编号 + 圆章，别每行都画插画
  - 加载：塞子拔出来的动画；下拉刷新：泡沫往上溅
  - 按钮反馈：弹，不变灰
- Dashboard（图表、大数字、表格）：
  - 大数字：Alfa Slab One 或 Shrikhand，朱红字黑投影，装在柠檬黄圆章或黑底方签里，一屏最多三个
  - 柱状图：每根柱子画成一只瓶子（或一根平涂粗柱 + 黑边 + 实心投影），只用 6 色里的 3 色，值标在柱顶的瓶盖上
  - 折线：4px 黑线 + 朱红圆点，背景不画网格，只留底轴一条 3px 黑线
  - 表格：行间 3px 黑线，表头黑底米字，排名列用 Shrikhand 大号数字
- 视频（镜头、转场、声音）：
  - 镜头：固定机位，像一张招贴在动；主角从画外跳进来过冲落定，大字一笔笔刷出来，最后定格成一张完整招贴
  - 转场：整块底色硬切成另一种颜色；或黑块从下往上压上来盖住画面
  - 声音：开瓶「啵」+ 气泡嘶嘶、手风琴或曼陀林小调、手鼓切拍子；每次字刷上来配一声刷子擦纸
- 海报设计：
  - 一块底色 + 一块黑 + 一个主角 + 一个品牌名，别的都不要；主角要有动作（跳、倒、甩）
  - 品牌名占画面宽度 80% 以上；小字只留日期、地点
  - 印刷感：6 色以内、石印颗粒、错位投影；不要照片、不要渐变

## 容易做坏

- 加了背景（街道、桌子、光效）——招贴的主角永远在平底上
- 底色用渐变，或者颜色太多、太灰，像普通插画
- 大字没投影、没斜，或者投影是模糊的 box-shadow，就成了普通标题
- 真图直接贴照片不压色，和平涂主角放在一起很脏
- 每个列表项都画一只瓶子，主角就不唯一了
- 动作太「顺」：招贴的动作要有冲劲和过冲

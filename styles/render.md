# 写实材质（render）

一张实时算出来的微距静物：胡桃木桌上一块拉丝铝铭牌，标题是激光刻进去的；一枚平凸玻璃透镜压在字上，把字放大、边上带一点彩边；后面是墨镜、红色车漆球、金球，全被浅景深化成柔和的光斑。光来自一张真实的落日 HDRI，太阳在左后方，影子朝镜头拖过来。内容就「长在」材质上：点列表里一条，铭牌换成那条的材质、刻上那条的名字。

出处：图鉴原来 60 种全是插画、印刷、复古界面这类「画出来」的风格，缺真光、真材质、真镜头，于是加了「写实 · 影像」一组。这一种学的是 3D 渲染师做材质研究（material study）的画法：基于物理的渲染（https://en.wikipedia.org/wiki/Physically_based_rendering）、HDRI 环境光、景深（https://en.wikipedia.org/wiki/Depth_of_field）。环境光 venice_sunset_1k 来自 Poly Haven（https://polyhaven.com，CC0，经 three.js 仓库）；墨镜模型 SunglassesKhronos 来自 Khronos glTF Sample Assets（https://github.com/KhronosGroup/glTF-Sample-Assets，Eric Chadwick，CC-BY 4.0）；景深的「在弥散圆里按黄金角取样、按样本自己的弥散圆加权」思路来自 Dennis Gustafsson 的单遍散景景深文章。

```css
:root { --bg:#121113; --panel:#1b1a1c; --ink:#f2efe9; --mute:rgba(242,239,233,.56); --faint:rgba(242,239,233,.34); --amber:#f0b27a; }

.seg button.on { background: rgba(255,255,255,.92); color: #111; border-radius: 7px; }   /* 光圈 f/1.4 f/2.8 f/8 */
.matname { font: 500 10px "JetBrains Mono"; color: var(--amber); letter-spacing: .04em; } /* BRUSHED ALUMINIUM */
```

```js
// 渲染管线（three.js r128，全部线性 HDR，最后自己做色调）
// 1. 不透明场景 → rtA（HalfFloat + DepthTexture），renderer.toneMapping = NoToneMapping
// 2. rtA 复制到 rtC；玻璃用自己的着色器画回 rtA：采样 rtC，偏移 = -(viewMatrix·(N - up)).xy × .045（平的地方不偏、球冠边缘放大）
//    RGB 三个通道偏移 × 1 / 1.012 / 1.024（色散）；菲涅尔 F = .04 + .96(1 - N·V)^5 混 HDRI 反射（RGBE 解码：rgb × 2^(a×255-128)）
// 3. 景深：半分辨率 alpha 存距离 → 弥散圆 coc = 36/N × |1/对焦 - 1/距离|（像素，上限 30）→ 28 个黄金角样本（远处样本的 coc 不超过中心 2 倍）
// 4. 全分辨率合成：清楚处用原图、糊处用半分辨率结果（smoothstep .6 → 2.2 px）→ 小号 FXAA → ACES → gamma 2.2 → 暗角 .6
// 太阳：取 HDRI 最亮像素的方向；整套布景转到太阳在左后方（+.42 rad），DirectionalLight #ffc28a 4.2 投软阴影
// 铭牌贴图 1280×876：拉丝 = 2.6 万条横向细划痕直接写像素（粗糙度 150±、凹凸 128±）；刻字处粗糙度 225、颜色压暗、凹进去
```

## 一眼认出（不能改）

- 整个画面是一次真实的 PBR 渲染：拉丝铝、玻璃、车漆、金、木头，各自对同一张 HDRI 有不同的反射
- 浅景深：只有刻字那一层清楚，前景木纹和后面的墨镜、小球都化成柔和光斑
- 一枚玻璃透镜压在字上：字被放大、透镜边缘彩边、底边一圈压暗
- 文字是「刻」在材质上的：更暗、更粗糙、往下凹，跟着板子一起反光
- 太阳在画面后方：暖色侧逆光，影子朝镜头拖
- 画面下沿一行等宽读数：焦距 / 光圈 / 对焦距离 / HDRI 名，全是真参数
- 列表每条左边一个实时渲染的材质球

## 颜色

- 页面石墨黑 `#121113`，面板 `#1B1A1C`；字暖白 `#F2EFE9`，次要 56%，更淡 34%
- 唯一的强调色琥珀 `#F0B27A`（落日的颜色）：材质名、选中的底栏
- 画面里的颜色全部来自材质参数：拉丝铝 `#C9CCD1`、抛光金 `#FFC35C`、玫瑰铜 `#F0A184`、车漆红 `#8E0D12`、黑色阳极 `#2A2A2E`、白瓷 `#EEEAE2`、喷砂钛 `#A29C94`、钢琴黑 `#0B0B0D`
- 不用任何 CSS 渐变当画面；只有读数条下面一层 55% 的暗底

## 字体

- Inter 600/700（标题、数字）+ Noto Sans SC；读数、材质名、编号用 JetBrains Mono 500，全大写、字距 .04–.08em
- 铭牌上的刻字：编号行等宽 → 名字 Inter 700 超大 → 中文副标题 → 一句近况 → 角落日期

## 真图怎么处理

- 不用照片；新闻内容变成材质上的刻字（`plateMaps()` 画三张贴图：颜色、粗糙度、凹凸）
- 封面图不进画面；列表只显示材质球，球是同一个 HDRI 实时渲染的
- 需要真图时：当成「印在相纸上的照片」放进场景（相纸材质：粗糙度 .5、微凸），也走同一套景深
- 页面写明「示意渲染」和 HDRI、模型署名

## 动效

- 入场：画面先是虚焦、很暗（对焦 2.4 m、曝光 .05），1.2 秒里拉焦到刻字上、曝光拉起来——像在取景器里对焦
- 点画面：射线找到点中的东西，对焦距离 0.5 秒滑过去，对焦框（金色方框 + 十字）闪一下
- 光圈 f/1.4 → f/8：只重算景深那一步
- 点一条：铭牌换材质、刻新名字，镜头绕 ±0.12 rad 慢慢转过去（0.9 秒）
- 场景只在变了的时候重画；对焦、光圈、曝光只重算后期

## 组件

- 头图：整块渲染画面 + 左上标题 + 右上「MATERIAL STUDY · 01/08」+ 下沿读数 + 光圈分段按钮
- 信息区：琥珀色材质名一行、标题、摘要、四个数字
- 材质库：每行左 64px 材质球（深底、贴地阴影）、右标题 + 材质英文名 + 热度
- 底栏：深色实底，选中琥珀色

## 换到别的东西上

- **网页 / 落地页**：首屏一张全宽实时渲染，滚动 = 推焦（对焦距离跟着滚动从前景走到后景）；每节换一种材质，标题刻在材质上；配一条等宽读数条
- **App**：参考页结构；商品、卡片、徽章做成实物材质（金属卡、玻璃卡），点开时镜头绕过去
- **Dashboard**：KPI 刻在拉丝金属牌上（大数字是刻字）；柱状图是一排不同高度的金属柱或玻璃柱，放在同一张桌面上一起被景深；折线是一根弯过的铜丝；表格是深色面板 + 等宽数字；只有选中的那块对焦清楚
- **视频**：微距滑轨镜头沿桌面平移，焦点在字之间来回拉；光从落日逆光慢慢转到侧光；转场用「失焦 → 对焦」；声音是很近的环境声：金属轻碰、玻璃放下的「嗒」、低低的室内空调底噪
- **海报设计**：一个物件占画面 2/3，标题刻在它上面，只有刻字那层清楚；底部一行等宽的「镜头参数」当署名行

## 容易做坏

- 景深用 CSS `filter: blur` 一刀切：要按深度算弥散圆，前景和后景糊的程度不一样
- 拉丝画得太粗太亮，变成条纹布；划痕要细、对比低、数量多
- 玻璃只做成半透明白片：要有折射（看得见放大的字）、菲涅尔边缘、底边暗圈
- 木纹画成同心圆或等距条纹；直纹 + 纹距变化 + 零星导管点
- SwiftShader（无头 Chrome）很慢：几千条 canvas 路径会在第一次上传贴图时才栅格化，卡好几秒——拉丝、木纹直接写像素；采样器状态（重复平铺、各向异性）每多一种就多编译一次，统一用默认；每帧画完用 `readPixels(1×1)` 等 GPU，免得帧越堆越多
- 编造镜头参数：读数要从相机算（`getFocalLength()`、当前光圈、当前对焦距离）

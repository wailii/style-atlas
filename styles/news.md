# 新闻包装（news）

电视新闻的包装：台标、LIVE、16:9 画面轮播、下三分之一字幕、突发黄条、滚动条。

出处：lemo-opuscar 风格库 news-package（示例片《The Week in AI》，https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/news-package/STYLE.md）。

## 直接抄

```css
:root { --bg:#f2f3f6; --red:#d7141a; --navy:#0b1f3a; --ink:#0d1424; --mute:#6a7386; --line:#dde1e8; --yel:#ffcc00; }
/* 字体 */ @import url("https://fonts.googleapis.com/css2?family=Roboto+Condensed:wght@500;700;800&family=Noto+Sans+SC:wght@500;700;900&display=swap");
/* 擦除缓动 */ --ease: cubic-bezier(.7,0,.2,1);
```

## 一眼认出（不能改）

- 左上台标（红 + 藏青两块）+ 闪烁的 LIVE + 走秒的时钟
- 16:9 画面，顶上分段进度条，几秒换一条
- 下三分之一字幕：红色小标签 + 白底标题（左边红竖条）+ 藏青副标题
- 底部一直在走的滚动条
- 红色擦除转场

## 颜色

- 浅灰底，红、藏青是主色，黄只给「突发」
- 字幕底必须不透明（压在图上要读得清）

## 字体

- Roboto Condensed 500 / 700 / 800（时间、数字、英文标签）+ Noto Sans SC 500 / 700 / 900

## 真图怎么处理

- 原色，不处理；每张图播放时从 1 慢推到 1.12（5.6s）

## 动效

- 轮播 5s 一条：红色面板（右边拖一条藏青）从左扫到右，中间换图，0.76s
- 字幕分四段推出：标签 120ms → 白条 260ms 擦开 → 标题 520ms 上推 → 副标题 700ms 擦开
- 突发：黄条擦开后，标签在黄 / 红之间闪 3 次
- 滚动条：内容复制一份首尾相接，40s 线性循环
- LIVE 点 1.2s 呼吸；时钟每 250ms 刷新

## 组件

- 主按钮：藏青方块「▶ 收听」，播放中变红
- 主卡：16:9 画面 + 角标「直播 · 第 01 条」+ 字幕
- 列表：「接下来」节目单：时间 | 标题 | 热度；当前条红色左竖条 + 浅红底
- 底栏：白底，红色顶线滑到当前项

## 换到别的东西上

- 网页：首屏就是演播室画面；侧栏放节目单
- 视频：每条 4～6 秒一个包装；声音用新闻片头音、滴答声、擦除时的嗖声
- 适合：资讯、赛事、发布会、直播

## 容易做坏

- 滚动条不复制一份会在结尾跳
- 黄色用多了像促销
- 字幕放半透明底会看不清

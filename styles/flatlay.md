# 俯拍平铺（flatlay）

相机正对桌面往下拍，东西一件件摆成横平竖直的网格（knolling）：照片冲印成相纸、新闻打在索引卡上、相机手表墨镜水瓶铅笔回形针按格子排好。整页就是一张俯拍照片——左上来的窗光、贴着桌面的接触影、往右下越来越虚的软影、纸边一圈细影、相纸表面一点反光。滚动是在桌面上平移，点卡片它就翻过来，点物件就被拿起来再放下。

出处：本库原来 60 种全是风格化（插画、印刷、漫画、复古界面），缺「看起来就是真的」那一类，所以加了「写实 · 影像」一组，这是其中的俯拍平铺。摆法来自 knolling——把东西按直角排整齐再从正上方拍，这个词出自 Frank Gehry 家具工坊的清洁工 Andrew Kromelow，后来艺术家 Tom Sachs 把「Always Be Knolling」变成工作室规矩，再变成产品摄影和社交平台上的 flat lay 套路。素材：照片来自 Unsplash（经 Hugging Face 镜像 `wtcherr/unsplash_5k`，https://huggingface.co/datasets/wtcherr/unsplash_5k）；3D 模型来自 Khronos glTF Sample Assets（https://github.com/KhronosGroup/glTF-Sample-Assets）：Chronograph Watch、Sunglasses（Eric Chadwick，CC-BY 4.0）、Antique Camera（Maximillan Kamps，CC0）、Water Bottle（Microsoft，CC0）；环境光用 three.js 自带的 RoomEnvironment。柔影算法是 PCSS（three.js 官方例子 webgl_shadowmap_pcss 的思路）加多光源位置累积。

```js
const cam = new THREE.PerspectiveCamera(40, 390 / 844, 50, 1300); cam.up.set(0, 0, -1);
cam.position.set(195, 422 / Math.tan(20 * Math.PI / 180), 422); cam.lookAt(195, 0, 422);
cam.setViewOffset(390, 844, 物件左 - 14, 物件上 - 14, 宽 + 66, 高 + 72);
// 窗光方向（左上、仰角约 50°）；累积时在 ±0.14 的圆盘里按黄金角取样 = 一块柔光箱
const SUN_DIR = new THREE.Vector3(-0.5, 0.76, -0.42).normalize();
// 两层：影子层（物件 colorWrite=false、depthWrite=false，只画 ShadowMaterial 桌面）+ 物件层（桌面隐藏）
new THREE.ShadowMaterial({ color: 0x24180c, opacity: .62 });   // 影子是暖黑，不是纯黑
// 累积：每个样本换光源位置 + 亚像素抖动，半浮点缓冲里 mix(acc, frame, 1/(i+1))；有显卡 24 次，烘图 64 次
// 柔影：shadowmap_pars_fragment 里插 PCSS——先在 0.03 半径里找遮挡物平均深度，半径 = (接收深度 − 遮挡深度) × 0.57
```

## 一眼认出（不能改）

- 镜头正对桌面，所有东西都是平放的，边和画框平行，间距一样（knolling）；没有斜放、没有叠在一起
- 光从左上一个方向来：每张纸右下都有一圈贴边细影 + 一片软影；3D 物件的影子贴着的地方实、越远越虚
- 桌面是有起伏、有颗粒的真材质（灰泥 / 亚麻 / 木），不是纯色
- 真照片冲印成相纸（白边、表面一道反光）或拍立得（底边宽、手写标注）；新闻打在索引卡（红头线 + 蓝横线）和卡纸上
- 至少两三件真 3D 物件（相机、手表、墨镜、水瓶、铅笔、回形针），PBR 材质，金属有环境反射
- 纸能翻面：背面是手写、印的相纸水印或下一层信息
- 字都「印」在纸上：衬线中文 + 等宽小字号读数 + 一点手写

## 颜色

- 桌面暖灰 `#C9C2B7` 上下浮动 ±15（程序纹理）；纸白 `#F8F6F1`，索引卡 `#F9F8F4`，标题卡 `#F4F1EA`（厚棉卡更黄一点）
- 墨 `#23201C`；读数用墨色 60%；手写蓝 `#24366B`（圆珠笔）
- 红只用在索引卡头线 `rgba(196,64,60,.5)` 和标题卡上的小圆章 `#B5322A`
- 颜色主要来自照片和物件本身（铜、金、玻璃、彩色封面）；界面不另加颜色
- 影子一律暖黑 `rgb(46,36,26)` 系，不用纯黑

## 字体

- 标题、卡片正文：Noto Serif SC 900 / 700 / 500——印刷品的感觉
- 读数、编号、署名：IBM Plex Mono 500 / 600，8～9px，像打字机或标签机打的
- 手写：Long Cang（中文）、Caveat（数字和英文），只出现在拍立得底边、相纸背面、方格纸上
- 状态栏、底栏是「界面」不是「照片」：Inter + Noto Serif SC 小号、字距拉开

## 真图怎么处理

- 照片不做风格化，原图放进相纸：`saturate(.94) contrast(1.02)`，四周 7～8px 白边，表面一道 118° 的淡白反光
- 有封面的条目用真封面冲印；没封面的配一张 Unsplash 照片当示意，拍立得底边手写「示意 · 摄影师」；一张都没有就画在方格纸上（热度曲线用圆珠笔蓝画）
- 示意照片只做气氛（键盘 = 编码模型、火箭 = SpaceX、云海 = Google Cloud），绝不当新闻现场照
- 3D 物件：镜片、表盘朝上平放；墨镜镜腿绕铰链折起来；表带圈、皮腔这种竖着很高的部分在 y 方向压到 0.4～0.6，否则影子长得像立着的东西
- 软件渲染（无头截图、没显卡）时用预渲染的两层 PNG（同一份代码 `?bake=1` 烘出来，64 次累积）；有显卡时载入 three.js 实时重拍

## 动效

- 入场：每件东西从「歪着、偏着、离桌一点」被推正放下（knolling），0.8s，间隔 75ms；放下前影子大而虚，落定时收成贴边细影
- 翻面：卡片沿横轴转 180°（0.8s），转到一半时往镜头抬 46px，影子同步变大变虚
- 拿起：物件层往左上抬 4～7px、放大 5%，影子层往右下走 9～13px、模糊 5px、变淡——两层错开就是「离开桌面」
- 有显卡时点手表：表针转一圈走到现在的时间，每帧实时重拍
- 滚动就是平移桌面；窗光、暗角、颗粒固定在画面上不动

## 组件

- 标题卡：厚棉卡、凸版大字 + 等宽小字一行 + 红色小圆章（条数）
- 主图：一张 6×4 比例的光面相纸，点它翻到背面（手写说明 + 相纸水印）
- 主卡：索引卡，头线上一行读数（No.01 · 热度 · 涨跌 · 来源 · 人数），线上印标题和摘要；背面是最新进展
- 列表：左拍立得（封面 / 示意照片 / 方格纸曲线），右米白卡纸（编号读数、两行标题、来源人数、一条小折线）
- 道具行：水瓶、铅笔、三枚回形针——它们是网格里的「分隔线」
- 署名纸条：照片作者、模型作者和许可，打字机小字
- 状态栏、底栏：近白磨砂条，选中项下面一条 14px 墨线

## 换到别的东西上

- **网页**
  - 首屏一整张俯拍桌面，产品或主角放在网格中心，周围是说明卡片；滚动 = 镜头沿桌面平移，新的一组东西进画面时一件件被摆正
  - 导航做成桌边的一排标签纸；按钮是「卡片翻面」或「拿起来」，不要做成浮在照片上的玻璃按钮
- **App**：参考 `gallery/s-flatlay.html`；列表行 = 一张照片 + 一张卡；详情 = 卡片翻面；收藏 = 把东西拿到一边的托盘里
- **Dashboard**
  - 图表：画在方格纸、索引卡上，线是圆珠笔蓝或铅笔灰，像手画的；柱状图可以真的用一排同样的小物件（回形针、硬币）堆高——数量必须等于真数据
  - 大数字：标签机打在黑胶带上，或印在厚卡上；单位用等宽小字
  - 表格：一叠横着排的卡纸，每行一张；表头是红头线的那张索引卡；排序 = 重新摆一遍
- **视频**
  - 镜头：顶拍固定机位（不转、不推）；变化靠「手伸进画面摆东西 / 拿走东西」和定格动画（每件 4～6 帧落定）
  - 转场：整桌从一边滑出（桌面平移）、或一张纸盖住画面再拿开
  - 声音：纸张摩擦、相纸放在木桌上的「嗒」、回形针的金属轻响、相机快门；配乐用安静的钢琴或 lo-fi 鼓
- **海报设计**
  - 整张就是一张俯拍：主物件在中间偏上，周围 6～12 件按网格摆，留一块干净桌面印标题（标题印在一张卡上，卡也有影子）
  - 光一定只从一个方向来；印刷前把影子的暖黑和纸白分开校色
- **PPT**：每页一张桌面，标题在卡上，要点是几张索引卡；换页 = 桌面平移

## 容易做坏

- 影子方向不统一，或者纸用 `0 10px 30px rgba(0,0,0,.3)` 这种「浮起来的卡片」影——平放的纸只有贴边细影 + 很淡的软影
- 东西斜着放、互相压着——那是 messy flat lay，不是 knolling；这个风格要横平竖直、间距相等
- 桌面纯色、纸纯白没颗粒：一眼就是网页，不是照片
- 3D 用默认的一盏平行光 + PCF 硬影：边缘锐利、离桌远的地方也一样实，很假；要面光源（累积或 PCSS）
- 竖着很高的模型（带表带圈的表、皮腔相机）直接平放，影子拖得很长；压扁或换成平的物件
- 拿示意照片假装是新闻现场；示意必须写在相纸上
- 全屏实时 WebGL：软件渲染下一帧要 2～5 秒，截图时什么都没出来——物件单独拍、能预渲染就预渲染
- 字号太大：纸上的字要像真的印刷品，标题 13～16px、读数 8～9px

## 参考实现

- 页面：`gallery/s-flatlay.html`——`L` 是 knolling 网格（单位 = CSS 像素），`paper()` 生成可翻面的纸（DOM，真文字），`obj()` 是 3D 物件的两层图；`tableURL()` 程序生成灰泥桌面（按窗光算好起伏明暗），`paperGrainURL()` 纸纤维
- 3D：同一文件下半部分——`shoot()` 每件拍两层（影子层 / 物件层），`fit()` 按投影后的大小缩放，`pencil()` / `clips()` 程序道具，PCSS 着色器片段在 `shadowmap_pars_fragment` 里替换
- 重新烘图：页面加 `?bake=1`，等 `window.__bake` 出现，取里面的 dataURL 存成 `gallery/img/real/flatlay-3d-<物件>.png` 和 `-shadow.png`
- 用到的图：`img/real/flatlay-keyboard.jpg`（Nik）、`flatlay-rocket.jpg`（SpaceX）、`flatlay-clouds.jpg`（Luke Pamer），都来自 Unsplash，旁边的 `.json` 有作者和 EXIF

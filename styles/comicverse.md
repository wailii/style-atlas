# 美漫宇宙（comicverse）

美式漫画的印刷品活了过来：真图拆成青、品红、黄、黑四版网点，每版网角不同、套印故意没对准；墨线粗黑，旁白框是黄的，拟声字在爆炸框里炸开；动作一拍二（12 帧/秒）一格格跳，四版从不同方向飞进来，落定那一下才对准；时不时一帧故障，画面横条错开。

出处：抖音 @Motdes AI阿峰《fable 5.5 网页设计的未来？》里录屏的 The Notturno Experience（意大利开胃酒品牌的滚动 3D 叙事网页）——同一个「漫画墨线 + 高冲击」家族；把印刷网点、套色错位、一拍二做进动画的手法来自动画电影 Spider-Man: Into the Spider-Verse（https://en.wikipedia.org/wiki/Spider-Man:_Into_the_Spider-Verse ）；网点见 https://en.wikipedia.org/wiki/Ben-Day_dots ，四色分版见 https://en.wikipedia.org/wiki/CMYK_color_model 。界面上不写这个片名。

## 一眼认出（不能改）

- 图片是看得见的四色网点：青、品红、黄、黑各一版，网角不同，叠出颜色（multiply）
- 套印不准：青和品红版各偏 2px 左右，而且每两格抖一下
- 粗黑墨线：图片描边、所有框 3～4px 黑边、实心黑色硬投影（不模糊）
- 黄色旁白框（「与此同时……」）、爆炸框里的拟声字和数字
- 柯比能量点：一团团冒泡的黑色圆点，装在品红 / 青网点的爆炸形里
- 动作一格一格跳（12 帧/秒），不顺滑；四版从不同方向飞来，落地才对准
- 每隔几秒一个故障帧：横条错开、一版跑偏

## 颜色

- 纸 `#FFF4DC`（旧新闻纸），底上铺一层很淡的青色网点
- 四版油墨：青 `#00A3E0`、品红 `#EC008C`、黄 `#FFE500`、黑 `#15110E`
- 爆炸框红 `#EE2A24`
- 放心改：爆炸框配色、旁白框的黄换成品牌主色；不能改：图片必须是四色网点 + 套印错位，颜色必须饱和

## 字体

- 拉丁、编号、旁白框：Bangers（它的数字 1 带长旗、像 7，数据里的数字用 Noto Sans SC 900 + skewX(-8°)）
- 中文标题、拟声字：ZCOOL QingKe HuangYou
- 正文、列表标题：Noto Sans SC 900，标题 skewX(-6°) 加 `.mis` 错位
- 刊头：黄字 + 7px 黑描边 + 三层叠出来的立体黑影 + 最外一层品红

## 真图怎么处理

- `cmykPlates()`：先把原图缩一半再放大（去噪），RGB → CMYK（黑版 = (1 − 最亮通道) × gcr，其余三版减掉黑），每版在自己的网角上逐像素算点：找最近格心、按格心颜色定半径（√浓度 × 半格 × 1.2）、按距离给覆盖率
- 四版各一张透明画布，叠在纸色上用 multiply；每张单独 transform，所以能错位、能飞进来、能抖
- 墨线：亮度梯度 > .18 的地方画 1.6px 黑线，叠在四版上面（不 multiply）
- `flat`：四版 + 墨线拍成一张，故障帧切条用
- 读像素的画布用 `getContext("2d", { willReadFrequently: true })`，省掉第一次从显卡读回的那一下（软件渲染下能差一秒多）
- 主图取原图中间 70%；小图网点 3.4px，只留青、品红两版单独错位，黄和黑合成一张
- 没封面：一种原色的放射网点底 + 青、品红、黑三条错开的图标线

## 线和形

- 爆炸框：`burst(cx, cy, rx, ry, n, seed, jag)` 星形，尖角长短随机，3.5px 黑边、圆角接头；后面再垫一个同形黑影偏 4px
- 柯比能量点：64 串，每串 2～5 个泡，从大到小沿放射方向排，每个泡上挖一个纸色高光；全部装进一个 22 角爆炸形里，外沿描黑
- 能量光晕：品红（7px 格）+ 青（9px 格）两层网点，离中心越远点越小
- 面板：倾斜 -2.5°～1°，4px 黑框，7px 实心黑影

## 动效

- 一律 12 帧/秒：`steps(n, jump-none)`，每格 83ms；数字也按格跳（8 格跳到真实热度）
- 入场：刊头从左甩进（4 格）→ 期号、按钮 → 能量爆炸形 3 格撑开 → 旁白框 → 主图面板 5 格飞进 → 四版各从不同方向 6 格飞来，第 6 格才对准，墨线这时才出现 → 标题卡 4 格升起，标题的错位从 18px 收到 2px → 拟声字 4 格砸下 → 爆炸框编号、热度 → 列表左右交替甩进
- 常驻：四版每两格（167ms）随机抖 ±.55px；标题错位同步晃；每 3.8～6.2 秒一次故障帧（两格：横条 10～55px 一段、水平错 ±18px、三分之一的条再叠一版青或品红偏 9px；面板整体偏 ±5px）
- 点击：卡片 3 格一顿；切底栏整屏两格故障（错位 + 青 / 品红投影）

## 组件

- 刊头：立体黄字 logo + 黑底期号「No. 22 / 10·22 · LIVE」；右边红色爆炸框按钮「听!」，点了变青「停!」并炸出「BLAM!」
- 主卡：能量爆炸形打底 + 黄色旁白框「与此同时，10 月 22 日……」+ 倾斜面板里的四色网点图 + 红爆炸框「No.1」+ 拟声字「轰!!」压在面板角上 + 白色标题卡（关键词黄底黑框、整句套色错位）+ 青色爆炸框里的热度数字
- 列表：「MORE!」黑底黄字；每条一个倾斜 ±.7° 的面板，左上角黄色编号签，右边网点小图；点开时卡片浅青底，摘要在黄色旁白框里
- 底栏：白底 3.5px 黑上沿；选中项后面一个黄色爆炸框（带品红错版影子），图标有青 / 品红错位

## 换到别的东西上

- 网页
  - 首屏一个倾斜大面板 + 能量爆炸形，滚动时面板一格格换（12 帧/秒），背景能量点慢慢转
  - 鼠标停在图片上：套印错位放大到 6px，移开收回；卡片 hover 硬投影从 7px 变 10px
  - 章节标题放在黄色旁白框里，「与此同时」「三小时后」这类时间旁白最合适
- App
  - 主按钮是爆炸框，按下 3 格缩放；成功反馈弹一个拟声字（POW、轰）
  - 页面切换用两格故障帧，不用滑动
  - 列表卡片倾斜不超过 1°，否则难读
- Dashboard（图表、大数字、表格）
  - 大数字放进爆炸框，一拍二地跳到真实值
  - 柱状图：每根柱子是一种原色的网点填充 + 黑框，柱子错位 2px；折线是 3px 黑墨线，下方面积用一种原色网点
  - 表格每行一个面板，表头黄色旁白框；异常值所在格加柯比能量点
- 视频（镜头、转场、声音）
  - 角色和前景按 12 帧/秒，镜头运动可以按 24 帧（原片的做法）；运动模糊用多重影像（同一物体留 2～3 个错版残影），不用真模糊
  - 转场：故障帧、整屏一版跑偏、分格切换（画面分成漫画格再合起来）
  - 声音：打击乐、合成器 hip-hop、拟声音效和画面上的拟声字同一帧出现
- 海报设计
  - 一张漫画封面：顶部刊头 + 期号框，中间倾斜面板四色网点主图 + 能量爆炸，角上一个大拟声字
  - 印刷时可以真的做套色错位：青、品红版各偏 1～2mm

## 容易做坏

- 用一种颜色的网点，那是孔版印刷或纸拼贴；这里是四版各自网角的四色网点
- 动作顺滑（60 帧缓动），就成了普通 UI 动画；必须一格一格跳
- 错位用模糊的 RGB 色散（屏幕感）——这里是印刷：青、品红、黄，硬边
- 投影用模糊阴影；这里只有实心黑色硬投影
- 拟声字、爆炸框太多，标题被淹掉；一屏最多一个拟声字、两个爆炸框
- 每个数字都用 Bangers：它的 1 像 7，数据要用无衬线
- 网点逐个画圆（几万个 arc）太慢，在慢机器上进场会晚一两秒；逐像素算

# 皮影戏（shadow）

一块被油灯从后面照亮的白布；染色的兽皮片贴在布上，颜色是透过来的光，镂空的地方最亮；人物是关节连着竿子的皮影。

出处：lemo-opuscar 风格库 shadow-puppet（https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/shadow-puppet/STYLE.md）。

## 直接抄

```css
:root { --cloth:#f6dcaa; --ink:#2a1a10; --ink2:#6e4a2c; --verm:#a8321f; --ochre:#c98a2a; --mala:#2f7d5b; --indigo:#2c4f8a; --lacq:#5b1a12; --gold:#c9a14a; }
@import url("https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@600;700&family=Noto+Serif+SC:wght@500;700;900&display=swap");
.hide { mix-blend-mode: multiply; }   /* 所有皮片都 multiply 到幕布上：镂空透亮、重叠变暗 */
```
```js
DYES = ["#2a1a10","#a8321f","#c98a2a","#2f7d5b","#2c4f8a","#e2b77a","#fff1d2"]
// 「贴上幕布」：blur(9px) scale(1.12) → 清楚，0.7s
```

## 一眼认出（不能改）

- 底是暖色发光的布（灯光一直轻微跳动），四周暖棕暗角
- 所有图形都是透光的染色皮：颜色发亮、重叠变暗、镂空最亮
- 皮片上有一排排镂空花纹（钱眼孔：圆孔中间留一个方块）
- 至少一个关节能动的皮影小人，关节有铆钉，手上连着竿子
- 东西出现时「贴上幕布」：先虚后实

## 颜色

- 3～5 种染料（朱红、赭黄、孔雀绿、靛蓝）+ 生皮色 + 墨色
- 没有比灯更亮的东西；晚上靠少点灯变暗，不加蓝
- 细的、要读的东西（字、竿子）用深色

## 字体

- Noto Serif SC 500～900；数字 Cormorant Garamond
- 标题本身是一块皮牌：深色皮上把字挖空，让光透出来

## 真图怎么处理

- 页面里的 `hide()`：`posterCanvas` 按染料调色板分色 + 描墨边 → 叠皮纹（multiply 的淡色椭圆斑）→ 在偏暗处打钱眼孔
- 布景外圈打一圈半圆花边，再描一道墨框

## 动效

- 灯：约 7 次/秒的小起伏 + 光斑位置缓慢漂
- 小人：身子 ±1.6° 摆、头跟着点、胳膊指向标题一抬一抬；竿子从手上垂直挂下来
- 皮牌在竿子上轻晃
- 「贴上幕布」：模糊 + 放大 → 清楚（离布远时影子虚）
- 点灯：灯数 +1，整屏更亮，灯里出现火苗

## 组件

- 主按钮：一盏挂着的红灯笼，点了点亮
- 头部：深红漆木横楣 + 金线（状态栏在上面）
- 主卡：镂空花边的布景（真封面）+ 指着它的皮影小人 + 圆形刻字印（编号）
- 分隔：一条镂空菱形的赭黄皮条
- 列表：染料色圆印编号 + 标题 + 兽皮小图
- 底栏：漆木底座，金色菱形标当前

## 换到别的东西上

- 网页：整页是幕布，章节是一出出戏
- 视频：照 lemo 规格——人物 8～12 片、两骨 IK、换场用后台视角；声音用板胡、梆子、锣鼓
- 春节、非遗、戏曲题材最合适

## 容易做坏

- 做成纯黑剪影（颜色是这个风格的第二主角）
- 皮片不用 multiply，叠在一起不会变暗
- 竿子跟着胳膊转（竿子应该一直垂直往下）

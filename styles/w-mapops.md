# 地图调度（w-mapops）
地图占满整个屏幕，所有工具都是浮在地图上的小玻璃面板。算力负载用六边形热力铺在全国轮廓上，底部时间轴一拖，热力跟着变。给调度和运营的人用，看哪里满了、哪里空着、往哪迁。

出处：kepler.gl（https://kepler.gl）；Mapbox Studio（https://www.mapbox.com）。

## 一眼认出（不能改）
- 底图占满视口：淡青灰的海、米白的国土轮廓、白色经纬网，没有瓦片
- 国土内铺一层六边形热力，五段暖色，配深色圆点节点
- 所有控件是毛玻璃浮层：左上摘要、左侧图层开关、底部居中时间轴
- 时间轴就是负载曲线本身，红色游标可拖，旁边是播放和倍速
- 点节点在旁边弹出小卡片，卡片里有 24 小时曲线和「调度」按钮

## 颜色
- 海 `#DFE6E7`；陆 `#FAF8F2`；墨 `#1C2230`；经纬线白
- 热力 `#F6E9CC → #F5C183 → #EA8052 → #C4384F → #7B2060`
- 高负载提示红 `#C4384F`；在线点 `#2F9E6A`

## 字体
- Plus Jakarta Sans + Noto Sans SC；Spline Sans Mono（数字、时间）

## 真图怎么处理
- 不用照片和瓦片。底图是手写的轮廓多边形，只求形状可认，不求精确

## 动效
- 拖动时间轴：六边形颜色 250ms 过渡；播放时每秒走约 1 小时
- 链路上白色虚线沿线流动；高负载（>85%）节点冒红色波纹
- 点「调度」：红色弧线 0.9 秒画出，一个红点沿弧飞过，弧线淡出，顶部落下提示

## 组件
- 摘要：在线 GPU、平均负载、高负载节点数，随时间变
- 图层面板：热力、链路、节点、名称四个开关
- 图例：五段色条
- 节点卡片：GPU 数、当前负载、可调度空闲、24 小时曲线（带当前时刻游标）、调度和迁出按钮
- 时间轴：播放、时钟、可拖曲线、1×/4×/12×

## 学什么交互
1. 时间轴本身画成指标曲线 → 拖的时候同时看到「现在在哪、峰值在哪」 → 费用明细页把日期选择做成月度费用曲线，点哪天就筛哪天。
2. 地图或主图占满，控件做成小浮层 → 主内容面积最大，浮层可随时收起 → 资源台账的机房分布图可以全屏，筛选、图例都收成浮层。
3. 图层开关直接放在图上 → 复杂的叠加关系用开关拆开看，比切页面快 → 算力分布里热力、链路、节点分开开关。
4. 六边形按附近节点加权，没节点的地方自然变淡 → 不会把空白区域画成「低负载」 → 区域级汇总用同样思路：无数据的区域淡出，不显示 0。
5. 点节点的卡片里直接放操作 → 看数据和下决定在同一个位置 → 部门负责人在利用率卡片里直接点「回收」。

## 换到别的东西上
- 适合：机房分布、网点、门店、运力、基站、配送范围
- 放大缩小用滚轮和按钮，本页没做缩放，数据多时需要

## 容易做坏
- 热力色阶用彩虹色，大面积刺眼
- 浮层不透明，压住底图
- 没数据的格子也上色
- 浮层太多太大，把地图挤成一小块

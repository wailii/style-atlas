# 暗场极光（w-aurora）
近黑底色上浮着一片缓慢流动的冷色光场，一层很淡的细网格，字细而干净。产品截图以透视倾斜的姿态出现，随滚动慢慢转正；功能卡片的边框会被鼠标「点亮」。适合开发者工具、AI 产品的落地页。
出处：Linear（https://linear.app/）；Raycast（https://www.raycast.com/）。

```glsl
// 光场（片元着色器）：域扭曲 fbm 噪声，只在页面上部中央出现，随鼠标整体偏移；网格线在同一个 shader 里画
vec2 q = p*1.6 + vec2(m.x*.5, m.y*.35);
vec2 w = vec2(fbm(q+vec2(0.,t)), fbm(q+vec2(5.2,1.3)-t));
float f = fbm(q + 2.2*w + vec2(t*2.,0.));
float v = smoothstep(.22,.8,f) * band * 1.7;            // band：顶部中央向下、向两侧衰减
vec3 col = mix(vec3(.30,.27,1.), vec3(.2,.88,.9), smoothstep(.3,.95,f+uv.y*.35+m.x*.2));
```
```js
// 截图转正：rotateX 从 34° 随滚动缓出到 0°，同时 scale .94 到 1
const e = 1 - Math.pow(1 - clamp(scrollY/460), 3); shot.style.transform = `rotateX(${34*(1-e)}deg) scale(${.94+.06*e})`;
// 卡片边框光：一张 canvas 盖在卡片网格上，对每张卡用以指针为圆心的径向渐变描 1.2px 边，并在卡内填一层很淡的光
```
## 一眼认出（不能改）
- 近黑底（`#06070B`），上方有一片缓慢流动的紫青色光场，不是 CSS 渐变球
- 一层 64px 的细网格，在光场最亮处最清楚，向下淡出
- 标题是 300 字重的大字，只有一个词加到 500
- 产品截图带透视倾斜入场，滚动后转正
- 功能卡片是 1px 细边的暗卡，鼠标经过时边框被一团冷光点亮
## 颜色
- 底 `#06070B`；字 `#E9EAF2`；次级 `#8B8FA3`；极淡 `#565A6E`
- 光场两端：靛紫 `#4D45FF` 到青 `#33E0E6`，只在 shader 里出现
- 强调紫 `#8D8BFF`（小标题、状态），青 `#5FE0E6`（日志里的「新增」）
- 主按钮反白：`#F2F3F8` 底、`#0A0B10` 字；次按钮只有 1px 亮边
- 代码 diff：增 `#46C88C`、删 `#F05A64`，底只有 10% 不透明度
## 字体
- Inter 300 / 400 / 500 + Noto Sans SC 300 / 400
- 代码与命令用 JetBrains Mono，12.5px
- 小标题用等宽小字，加字距
## 真图怎么处理
- 不用照片；产品截图用 HTML 搭成假界面（文件树、编辑器、助手面板），保证清晰
- 光场用 WebGL 片元着色器，画布是视口一半大小，CSS 拉伸，既省性能又自然柔和
## 动效
- 光场持续缓慢流动，鼠标移动时整片光向反方向偏一点，插值 4% 每帧
- 滚动时光场整体减弱到 40%
- 截图倾斜到转正：滚动 460px 内完成
- 卡片光：鼠标进入时透明度 12% 每帧趋近 1，离开时淡出
- 按钮悬停上浮 1px
## 组件
- 导航：品牌、四个链接、登录、「开始使用」
- 版本胶囊：绿紫小标加一句说明
- 命令行条：`$ npm i -g …` 加「复制」，点击后变「已复制」
- 倾斜截图：标题栏、文件树、带 diff 的编辑器、助手面板（步骤清单、应用修改）
- 功能卡：图标、标题、说明、命令行；一张卡可跨两列
- 更新日志：左侧一句话，右侧固定高度的滚动列表，上下边缘渐隐
## 学什么交互
- 光场随鼠标轻微偏移 → 页面是活的，但不抢内容 → 放到后台：登录页或空状态页用极淡的动态背景，操作区仍保持安静。
- 截图透视转正 → 让第一眼看到「这是个真产品」，再慢慢看清细节 → 放到后台：新功能公告页，先倾斜展示一张后台截图，滚动后转正并出现标注。
- 卡片边框跟随指针发光 → 不加任何装饰也能给出「可点」的反馈 → 放到后台：模型市场、功能入口卡片用这种边框光，替代常见的上浮阴影。
- 固定高度滚动日志 → 页面不被无限拉长，版本历史也一直可查 → 放到后台：变更记录、审批轨迹用带渐隐边缘的固定高度滚动区，放在详情页侧边。
## 换到别的东西上
- 适合：开发者工具、AI 产品、命令行工具的落地页
- 不适合：需要大量彩色编码的数据页，暗底上的彩色会互相抢
## 容易做坏
- 光场太亮或颜色太多，变成屏保
- 网格线可见度过高，抢过字
- 标题用粗体，细字带来的精致感就没了
- 用 CSS 渐变画光球，边缘有色带，也失去流动感
- 截图倾斜后文字糊，需要把字号和对比度做足

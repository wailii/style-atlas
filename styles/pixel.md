# 像素（pixel）

16-bit 游戏的白天关卡：像素天空和云、像素窗口、点阵中文、打字机对话框，热点是任务、热度是血条。

出处：Majid Manzarpour「像素巫师」规格型提示词（低分辨率画布、固定调色板、8～12 帧/秒，https://x.com/majidmanzarpour/status/2102476499387383834）；lemo-opuscar 风格库 pixel-rpg（https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/pixel-rpg/STYLE.md）。

## 直接抄

```js
// 16 色调色板
PAL = ["#2b2b45","#4a4a6a","#8d8aa8","#c9c6dc","#ffffff","#fff7dc","#ffd541","#ff9a3c","#f25454","#b03a5a","#7b5cf0","#3d6fe0","#5ab8ff","#a8dcff","#4cbf4f","#2e8a4a"]
// 总时钟 125ms（8 帧/秒）；放大倍数只用 1.5 / 2 / 3（2 倍屏上都是整像素）
```
```css
canvas { image-rendering: pixelated; }
.win { filter: drop-shadow(3px 3px 0 #2b2b45); }
.win > .in { border: 3px solid #2b2b45; clip-path: polygon(3px 0, calc(100% - 3px) 0, calc(100% - 3px) 3px, 100% 3px, 100% calc(100% - 3px), calc(100% - 3px) calc(100% - 3px), calc(100% - 3px) 100%, 3px 100%, 3px calc(100% - 3px), 0 calc(100% - 3px), 0 3px, 3px 3px); }
```

## 一眼认出（不能改）

- 所有字（包括中文）都是点阵
- 所有图都是 16 色抖动像素图
- 窗口：3px 粗边、切角、实心投影
- 一切按 8 帧/秒走（云、星、角色、光标）
- 白天：浅蓝天空 + 白云 + 绿草地（不是夜空）

## 颜色

- 只用调色板里的 16 色；面板奶白 `#FFF7DC`，边框 `#2B2B45`

## 字体

- 不加载字体。`pxText()`：用系统中文字体在小画布上画 10～16px 的字，透明度大于 105 的当实点、其余去掉，再整数倍放大
- 标签 12px、字重 500；10px 粗体的复杂汉字会糊成一团

## 底和纹理

- 天空：130×282 的低分辨率画布，5 条色带 + 一格一格往左挪的云 + 正弦起伏的草坡

## 真图怎么处理

- `pixelCanvas(img, 108, 56, PAL, .1)`：缩小、按调色板取色、4×4 Bayer 抖动；小图 22×18

## 线和形

- 图标：`pxIcon(path)` 把矢量路径画到 12～16 格上再一刀切
- 角色：字符画数组 → 画布（`sprite()`），两帧交替就是眨眼
- 血条 / 经验条：一排小方块，按热度点亮，红 / 黄 / 绿

## 动效

- 总时钟 125ms：云、星星（调色板从白到暗红循环）、机器人眨眼和上下跳
- 窗口打开：clip-path 从中线往上下 `steps(5)` 展开
- 对话框：打字机，每字 45ms，结尾 ▼ 闪
- 点一条：光标跳过去、窗口左右晃 2 下、弹「+1 EXP」往上飘（`steps(6)`）

## 组件

- 主按钮：黄色像素窗口 + ▶ + 「听热点」；播放时变橙，对话框重新打字
- 主卡：紫色任务标题栏「★ 头条任务 01 / 热度 455」+ 像素图 + 标题 + 血条 + 小人头像 + 对话框
- 列表：每条一个窗口，「LV.2」黑底黄字 + 标题 + 经验条 + 像素小图
- 底栏：奶白窗口，当前项反色

## 换到别的东西上

- 网页：整页是一个关卡；滚动时云和草坡有视差
- 视频：照像素巫师提示词——128×96 逻辑画布、整像素、8～12 帧/秒；声音用方波 / 三角波芯片音乐、金币声
- 适合：打卡、习惯、游戏化

## 容易做坏

- 非整数放大会糊——在 2 倍屏上只用 1.5 / 2 / 3
- 中文字号小于 12px 会糊
- 用了调色板外的颜色

# 卫星实景（satellite）

整页是一个卫星 / 航拍地图 App：真航拍铺满上半屏，可以拖、可以放大；每条内容是一处「关注区」——黄框框住图上的一个真实地物，框边量出尺寸，一条剖面线穿过去，下面的抽屉把剖面画成「高程图」。画框上有网格字母、十字准星、比例尺、指北针、坐标读数和影像署名。看起来像在用 Google Earth，也像 OSINT 调查里那种在卫星图上画框标注的图。

出处：本库原来 60 种全是风格化（插画、印刷、漫画、复古界面），缺「看起来就是真的」那一类，所以加了「写实 · 影像」一组，这是其中的卫星实景。界面语法来自地图 App 的通用做法（Google Earth 一类：顶部搜索框、右侧圆形工具钮、底部抽屉、角落的比例尺和影像署名）和开源调查报道里的卫星图标注（黄框、尺寸线、编号标签、剖面）。影像全部是 Unsplash 上的真航拍（经 Hugging Face 镜像 `wtcherr/unsplash_5k`，https://huggingface.co/datasets/wtcherr/unsplash_5k），作者：Maximillian Conacher、Victor、Alexander Londoño、Michael Olsen、Andreas M、Alexander Pidgeon；EXIF 读自照片本身。照片没有定位数据，所以这一页**不写经纬度**：位置一律是图像网格（A–H × 1–6）和 0～1 的图像坐标，比例尺按原图像素，指北针标「示意」。

## 一眼认出（不能改）

- 底图是真的正射航拍 / 卫星图（屋顶、道路、树冠、船、球场），铺满上半屏，能拖能缩放
- 黄框关注区 + 黑底白字编号标签（`AOI-01`），框下垫暗边；框边有尺寸线和数字
- 白色虚线剖面 A–A′ 穿过关注区，抽屉里把它画成灰色面积的「高程图」（这里的高程 = 24 小时热度）
- 画框上：网格字母和行号、正中十字准星、左下比例尺 + 坐标读数、右下影像署名和相机参数、右侧指北针
- 地图 App 的壳：顶部白色搜索胶囊、右侧圆形白工具钮（图层、+ −、指北）、底部白色圆角抽屉
- 等宽数字到处都是：坐标、尺寸、热度、百分比
- 没有定位就不写经纬度：坐标写「图像坐标」，比例尺写像素，指北写「示意」

## 颜色

- 影像本身决定画面主色（绿、灰、砖红、海蓝）；界面只用白、深灰和一种黄
- 关注区黄 `#FFD60A`，黄底上的字 `#1A1500`；压在影像上的读数条 `rgba(18,20,23,.78)`
- 抽屉：白底、墨 `#1B1E23`、次要 `#5D636D`、分隔线 `#E3E5E8`；选中蓝 `#0A66C2` 只给底栏选中项和列表选中行
- 涨跌：涨 `#0F8A4A`、跌 `#C7362B`、持平用墨色 `▶`
- 剖面图：面积 `rgba(93,99,109,.16)`、线 `#2C3138`、峰值红圈 `#C7362B`

## 字体

- 界面：Inter + Noto Sans SC（地图 App 的中性无衬线），标题 18px 700
- 读数：JetBrains Mono 500～700，9～11px——坐标、尺寸、编号、比例尺
- 压在影像上的字一律白字 + 黑色描影（`text-shadow: 0 0 2px #000`），或放进深色读数条

## 真图怎么处理

- 只用正射（正上方往下拍）的航拍：无人机 DJI 那种最好；斜拍的城市照片只能当次要图
- 在画布里做遥感味：反锐化、提反差、略降饱和、一层很淡的大气蓝雾；不加滤镜色调、不加暗角
- 放大到能盖满地图区（cover × 1.02），会有点软——这正像放大到极限的卫星图，不要锐化过头出白边
- 列表小图从同一张影像里按关注区裁一块（框的 1.6 倍范围），画上同样的黄框和编号
- 署名写在画面右下：「影像 © 作者 / Unsplash（示意）」+ 相机参数（来自 EXIF）；抽屉底部再写一遍所有作者和「与新闻事件无关」

## 动效

- 入场：影像先整张模糊低清，再一块块瓦片变清楚（从中心往外）；然后黄框沿边画出来（0.6s）、剖面虚线从 A 画到 A′（遮罩揭开，0.9s）、尺寸和标签弹出；抽屉从下面滑上来，列表一行行出现
- 点列表某一行：地图「飞过去」——当前影像糊掉变暗 0.28s，换成那一处的影像，瓦片重新加载，标注重画；抽屉头部换成这一处
- 拖动：影像和标注一起平移，网格字母、坐标读数实时变；+ − 以十字准星为中心缩放（0.9s 缓动）
- 指北针：回到当前关注区；图层钮：标注开关
- 剖面图的线从左往右画出来，峰值点最后出现

## 组件

- 搜索胶囊：放大镜 + 「AI 热点 10.22 晚 · 8 处关注区」+ 右侧圆形头像位（点它回到 01）
- 右侧工具：图层（标注开关）、+ − 缩放、指北针（写「示意」，点它复位）
- 关注区标注：黄框 + 暗边 + `AOI-01` 标签（编号黄底、标题和热度深底）+ 两条尺寸线（原图像素）
- 剖面线：两个白圆点 A、A′ + 白虚线
- 读数：比例尺（原图 100 px）+ 「网格 E4 · x 0.500 y 0.501」；右下署名第三行写「无定位数据 · 坐标为图像坐标」
- 抽屉头：`AOI-01` · 网格 · 中心坐标 → 标题 → 四个描边胶囊（热度、涨跌、来源、人数）→ 剖面卡（24 小时热度、峰值）→ 摘要
- 列表行：76px 圆角小图（带黄框编号）+ `AOI-02 · 网格 E3` + 两行标题 + 热度涨跌来源
- 底栏：白底，选中项图标外面一个浅蓝胶囊

## 换到别的东西上

- **网页**
  - 首屏全屏地图，左侧一栏是关注区列表（桌面端把抽屉换成侧栏）；滚动叙事 = 一处处「飞过去」，每到一处黄框画出来、标注弹出
  - 有真坐标的项目（门店、工地、物流点）才能写经纬度和真实比例尺；没有就照这里用图像网格
- **App**：参考 `gallery/s-satellite.html`；详情页 = 抽屉拉高；收藏 = 给关注区加一个星标图钉
- **Dashboard**
  - 图表：剖面图（面积 + 线 + 峰值点）当时间序列；柱状图画成「测量条」——黄色尺寸线两端带短竖线，旁边等宽数字
  - 大数字：深色读数条里的等宽数字（像坐标读数），单位小一号、60% 白
  - 表格：每行一处关注区，第一列是小图 + 编号，第二列网格号，后面是读数；选中行和地图上的框联动高亮
- **视频**
  - 镜头：从高空俯拍一路推进（缩放时影像先糊再变清楚，像瓦片在加载）；在关注区上停住，黄框画出来，尺寸线一根根拉出
  - 转场：「飞过去」——拉远、平移、再推近到下一处；或者影像整张糊掉再换
  - 声音：低频环境铺底、轻微的数据「滴」声配合标注弹出、键盘敲击配合坐标数字跳动；不要激昂配乐
- **海报设计**
  - 一张正射影像铺满，一个黄框 + 编号标签 + 尺寸线，标题放在一条深色读数条里；四角放网格字母、比例尺、指北、署名
  - 印刷时黄框加粗到 1.5mm 以上，暗边保留

## 容易做坏

- 编经纬度、编真实比例尺（「50 m」）、给照片编地名——照片没有定位数据就只能写图像坐标和像素，指北写示意
- 用斜拍的城市风光照当卫星图：一眼就不是正射
- 标注颜色太多（红、蓝、绿框一起上）；这个风格只有一种黄，其余都是白和深灰
- 黄框下不垫暗边，在浅色屋顶或沙滩上看不见
- 影像加滤镜色调、暗角、颗粒——遥感图是「干净但有点软」的
- 地图不能拖、标注不跟着影像动：做成了一张图片，不是地图
- 把示意照片说成新闻现场；署名和「示意」必须在画面上

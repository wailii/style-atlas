# 设备实拍（device）

一张真实拍摄的设备照片：平板电脑放在树桩凳上，旁边是棕榈叶和贴满杂志的墙；平板屏幕上显示的却是你的界面——页面按照片里屏幕的四个角算出单应矩阵，把界面逐像素透视贴上去，再按原屏幕的白点和明暗调色、叠一层玻璃反光和颗粒；挡在屏幕前的棕榈叶从原图里抠出来留在最上面。点列表里一条，照片里的平板就切到那一条。

出处：图鉴原来 60 种全是插画、印刷、复古界面这类「画出来」的风格，缺真照片、真光线的写实风格，于是加了「写实 · 影像」一组。这一种是产品发布、App Store 截图、设计作品集里最常见的「设备样机」实拍图：真照片 + 屏幕替换。屏幕替换的数学是单应变换（https://en.wikipedia.org/wiki/Homography_(computer_vision)）。照片来自 Unsplash（经 Hugging Face 镜像 https://huggingface.co/datasets/wtcherr/unsplash_5k），摄影 Olena Sergienko（https://unsplash.com/photos/Lie7rRI-5Cc），SONY ILCE-7M3 50mm f/1.8 1/400s ISO 160。这批照片里没有手持手机、屏幕朝镜头的可用图，参考页用的是平板；换成手持手机的照片时做法完全一样。

const quad = [[187.7, 138.0], [384.4, 162.6], [350.2, 319.0], [153.8, 283.3]];   // 左上、右上、右下、左下
// 2. 单应矩阵 H：画布像素 → 屏幕 (u,v)∈[0,1]²；8 元线性方程高斯消元
// 3. 每个像素：u,v → 双线性采样界面画布（界面按 1.43:1 画，先 blur(.7px) 和照片的锐度对齐）
//    覆盖度 = 到四条边的像素距离 + .5（抗锯齿），四角按 3.2% 宽的圆角裁
//    亮度 = 原屏幕白点（照片里屏幕上 >205 的像素平均）× 背光 × (.94 + .06(u - v))（窗光那侧更亮）
//    反光 = 宽斜带 exp(-((.8u + 1.1v - .62)/.16)²) × .09 + .03，用滤色叠；再加 ±3.5 的固定颗粒
//    遮挡 = 原图像素「绿 - max(红, 蓝) - 5」/ 14（棕榈叶），外扩一像素再模糊；遮挡处用原图

## 一眼认出（不能改）

- 底是一张真照片，有真的景深、真的环境（这里：杂志墙、棕榈、树桩、键盘、笔）
- 屏幕上是你的界面，透视、圆角、边缘和照片里的设备严丝合缝
- 屏幕亮度和色温和照片一致，不是贴上去的一块纯白；有一层斜向玻璃反光
- 挡在屏幕前的东西（叶子、手指）还在屏幕前面
- 屏幕和照片一样软、一样有颗粒，不比照片更锐
- 照片左上一个黑底小标签「示意图 · 屏幕为实时合成」，下面一行摄影署名 + 真 EXIF
- 点列表，照片里的设备跟着换内容

## 颜色

- 页面纯白 `#FFFFFF`；字 `#111214`，次要 `#6B6D72`，更淡 `#9A9CA1`，分隔线 `#E6E6E8`
- 唯一强调色朱橙 `#E8452C`：「● 实拍预览」、当前在屏幕上的那一条
- 屏幕里的界面用浅色主题（`#FBFBFC` 底），这样才能和原屏幕的白点对上

## 字体

- Inter 800（大标题，字距 -0.03em）/ 600 + Noto Sans SC
- 屏幕里的界面也用同样的字，按平板尺寸画（标题 64px、条目 25px，画布 1432×1000）
- 署名和 EXIF 11px；EXIF 原样照抄照片元数据，不改写

## 真图怎么处理

- 选图：屏幕要大、正、四条边都看得见，最好原屏幕是浅色（好取白点）；有东西挡屏幕更真，但要能按颜色抠出来
- 照片只缩放裁切，不调色、不加滤镜——要调的是贴上去的屏幕，让它去配照片
- 四个角用边缘拟合求，不靠目测；误差 1 像素以内
- 屏幕里的新闻封面原图放在界面卡片里，跟着整个屏幕一起透视
- 照片的 `.json` 附带摄影师、Unsplash 页面、EXIF：署名和 EXIF 从这里读，不自己写

## 动效

- 入场：照片从模糊 6px 淡入（0.7s）；0.5 秒后屏幕亮起来——先闪到 35% 再缓到 100%（0.9s），像唤醒设备
- 切换内容：新界面在屏幕上淡入 0.38s（整个合成每帧重算，透视不变）
- 点照片：熄屏 / 亮屏（0.45s）
- 列表、署名依次上浮出现

## 组件

- 顶部：大标题「AI 热点」+ 右侧红点「实拍预览」和日期
- 实拍图：430px 高，左上示意标签；点一下熄屏 / 亮屏
- 署名行：「示意图」加粗 + 一句说明 + 摄影师 / Unsplash，下一行 EXIF
- 列表：编号、标题、数据；当前在屏幕上的那条浅灰底、编号变红、右侧「屏幕上」
- 底栏：浅色实底，点哪个，屏幕里平板版界面顶部的标签也切到哪个

## 换到别的东西上

- **网页 / 落地页**：首屏全宽实拍图，屏幕里是产品真界面；滚动时屏幕里的内容跟着滚（只改界面画布，透视不变）；多张照片对应多台设备（桌上的笔记本、手里的手机），同一份界面各自贴上
- **App**：App Store 截图式：上方一句卖点，下方设备实拍；参考页这种「点列表、照片里的设备换内容」可以做产品演示页
- **Dashboard**：把整个 Dashboard 画在一张画布上，贴进会议室大屏或桌上显示器的照片里；图表、大数字、表格按真界面画（浅色主题、细线、等宽数字），屏幕外的照片当环境；屏幕亮度、反光照参考页调
- **视频**：一段手持设备的实拍视频，四个角每帧跟踪（或手动打关键帧插值），每帧重算单应矩阵；屏幕里的界面按真实操作节奏滚动、点击；声音用环境实录（咖啡馆、键盘声）+ 一两下真机的触感音
- **海报设计**：一张大实拍占满画面，界面贴在屏幕上，标题压在照片暗部；署名和 EXIF 小字放在角落

## 容易做坏

- 把截图直接用 CSS `transform: perspective()` 斜一下贴上去：不对齐、太锐、太亮，一眼假——要单应矩阵逐像素算
- 屏幕用纯白 `#FFF`：照片里的屏幕白点通常是 220–235 的灰，还带色温
- 屏幕比照片锐：界面画布先模糊 0.5–1px，再加和照片一样的颗粒
- 忘了遮挡：叶子、手指、反光要留在屏幕前；只在可能被挡的那一片区域里抠，别把界面里的绿色图标当叶子
- 四个角目测：差 2 像素边上就会露白或吃掉边框
- 把示意照片当成新闻现场：一定写「示意图」和署名
